# 高清快捷栏图标

使用本机 `D:/Flux` ComfyUI 的 Qwen Image 2.1 INT8 ConvRot，以 `../legacy/` 中八枚原始图标组成的参考图进行高清重绘。保留原图形含义和主配色，统一轮廓与细节；原始16×16资源继续保留。

- 生成：1536×768参考图编辑，4列×2行，30步，CFG 1.0，Euler/Simple，seed 2026102008。
- 输出：每枚256×256透明PNG，常规显示24×24 CSS像素；使用正常平滑缩放，支持系统高缩放。
- 快捷栏只显示图标，名称和用途在鼠标悬停时显示；按钮仍提供无障碍名称和键盘焦点。
- 提取：按格裁切，仅移除与格子边缘相连的近白背景，保留图标内部的白纸、标签和播放三角形；统一边距后缩到256×256。方法参数图标在深色主题中增加亮度以保持灰色列表线条可辨。
- 功能映射与 `../legacy/README.md` 一致。仅资源与显示方式改变，快捷栏动作、权限及布局保持。
