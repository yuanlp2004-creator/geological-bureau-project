- 样品表工具栏：只读提取 `Spec Source/Source/Main/mmAnalyze/FmDockAwareSam.dfm` 的 `IlSamp`。
- 编号含义和动作以 `FmView.dfm/.pas`、`FmViewSingle.pas`、`FmDockAwareSam.dfm/.pas` 为准。
