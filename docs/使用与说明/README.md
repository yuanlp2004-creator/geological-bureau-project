# 使用说明与手册

推荐打开 **[GeoSpectrum 使用手册](GeoSpectrum_使用手册.html)**。这是一个独立的离线 HTML 文件，双击后用 Microsoft Edge 等现代浏览器阅读，不需要启动 GeoSpectrum 或连接网络。

- 10 章、54 个主题，覆盖当前 28 个菜单入口。
- 左侧分层目录、右侧说明页、正文相关主题跳转。
- 全文搜索、面包屑、前进/后退、上一页/下一页、页内目录。
- 字号调整、当前页打印及小屏导航。

复制手册时只需复制 `GeoSpectrum_使用手册.html`；文件内已包含正文、样式和交互，不依赖旁边的文件。
