# GeoSpectrum 具体使用说明

适用版本：GeoSpectrum 0.1.0 Windows x64 内部测试版  
文档范围：主文件夹便携运行、首次初始化、日常分析主流程、旧版迁移、维护与故障排查  
说明形式：本页为文字说明；软件内“帮助 → 离线帮助”提供33个精简操作主题、6处示例截图、参数表和全文搜索

现状校订：2026-10-25。对应主目录最新配对内部测试版；当前验证状态见 [验收索引](../acceptance-reports/README.md)。

本次补齐的十四项操作及入口见[实施清单](../acceptance-reports/S24/artifacts/2026-10-16-legacy-fourteen-completion/实施清单.md)。其中曲线横轴为含量、纵轴为强度；旧SAM默认按GB18030原字节读取，UTF-8可显式选择；报告可选旧版矩阵或完整明细长表；导入的旧软件偏好需先预览再应用。旧Access文件仍只读，保存强度采用新版文件，校正位置仍生成待审核的方法草稿。

## 一、启动前须知

项目主文件夹中需要同时保留以下两个文件：

- `GeoSpectrum.exe`：桌面前端和主程序。
- `geospectrum-backend.exe`：本地后端服务，由主程序自动启动。

两个文件必须放在同一文件夹中，不要单独移动、改名或只复制其中一个。正常使用时只双击 `GeoSpectrum.exe`，不要单独双击后端文件。

软件运行数据默认保存在 Windows 当前用户数据目录 `%LOCALAPPDATA%\cn.geospectrum.desktop`，不会保存在这两个 EXE 旁边。关闭主窗口时，主程序会自动停止本次启动的后端进程。

当前版本是未签名内部测试版。Windows 若显示安全提示，请先确认文件来自本项目且哈希未变化，再选择继续运行。当前真实自动转角和汞灯硬件仍缺少现场协议及硬件在环验收，只能使用软件模拟器完成现阶段操作；不要把模拟结果当作真实设备验收结果。

## 二、首次启动和登录

### 1. 启动软件

1. 打开项目主文件夹。
2. 双击 `GeoSpectrum.exe`。
3. 等待窗口出现。主程序会自动选择一个空闲的本机端口并启动 `geospectrum-backend.exe`。
4. 不要关闭或结束后端进程；它由主窗口统一管理。

### 2. 第一次使用时创建管理员

如果本机数据库中还没有账户，界面会显示“初始化本地管理员”。

1. 输入管理员用户名。
2. 输入至少 8 位密码。
3. 在“确认密码”中再次输入相同密码。
4. 点击“创建管理员”。
5. 返回登录页后，用刚创建的用户名和密码登录。

软件没有预设通用管理员密码。请妥善保存首次创建的账户信息，不要通过删除数据库的方式处理忘记密码问题。

### 3. 已经初始化过的电脑

1. 在“登录工作台”输入现有本机用户名和密码。
2. 点击“登录”。
3. 如果提示“用户名或密码错误”，先检查输入法、大小写及账户是否已被停用。
4. 如果页面一直显示账户状态异常，可点击“重新检查账户状态”。

## 三、首次使用的完整操作顺序

以下顺序适合第一次建立一套可采集、可分析、可出报告的工作环境。

### 第 1 步：检查工作台和本地服务

1. 登录后进入左侧“工作台”。
2. 打开“工作台概览”。
3. 确认本地服务显示为运行状态。
4. 查看当前方法；首次使用时通常显示“请选择已发布方法”。
5. 查看最近运行消息。如果出现错误，记下错误码和错误内容。
6. 版本和版权见“帮助 → 关于软件”；管理员确认数据库路径及运行状态时，进入“系统管理 → 备份与维护 → 系统诊断”，点击“刷新诊断”。

左侧导航按权限显示七组入口：工作台、光谱方法、分析测试、数据处理、工具、系统管理和帮助，共25个正式入口。某个入口不可见通常表示当前账户没有对应权限；入口可见但灰色通常表示尚未选择当前方法或当前方法已暂停。

### 第 2 步：设置目录、显示、日志和打印默认值

进入“系统管理 → 软件设置”。

1. 设置“备份目录”，用于在线备份。数据、方法、样品和导出四个未接入的默认目录已不提供编辑入口；导出时仍在相应操作中选择位置。
2. 选择浅色或深色主题，以及舒适或紧凑信息密度。
3. 在“分析参数”中设置“空白传输时间（秒）”，默认8秒、范围6–20秒。编辑方法采样周期时，据此重算空白次数；已有方法未编辑时保持原次数，也可手动修改。
4. 需要时展开“高级维护设置”调整日志与时区，核对默认纸张和打印前预览设置。
5. 点击“保存设置”，再检查加载后的值。修改备份目录不会搬迁数据库。

“恢复默认”会恢复设置草稿；确认无误后仍应点击“保存设置”。

### 第 3 步：直接打开文件，或批量迁移旧数据

日常使用在各页面标题栏右侧点击“打开方法”“打开谱文件”等按钮，与刷新等操作同组。桌面版所有打开文件和选择目录入口共用最后一次选中的文件夹，切换页面和重启后仍记得；取消选择不改变位置，文件夹失效时恢复系统默认位置。兼容文件由程序只读校验、转换并保存到新版数据库，重复打开复用已有记录，不需要先去迁移页面。新版方法和记录仍从现有列表选择使用；目前没有独立的新版便携方法文件格式，PDF/文本是输出资料。

顶栏“打开方法”会直接进入方法页并弹出选择框，选择已保存的方法后点击“打开所选方法”，即可载入参数与谱线并设为当前运行方法；不必再次寻找页内操作按钮。选择框内的“打开方法文件”仍可打开兼容方法库。取消不切换方法，失败保留选择以便重试，当前编辑尚未保存时会先提示保存。新建与另存为直接打开名称表单，方法参数和分析谱线直达对应页签，预录样号直接聚焦样品名输入框。摄谱与分析进入各自操作工作区，按页内条件确认后执行。左侧一级导航只显示文字，图标保留在展开菜单中。

| 功能 | 打开入口与文件 |
|---|---|
| 方法管理与参数 | 打开方法：选择 MTD，同目录须有 DIRECT.CFG 和 DIRECT.OPT；随后在方法列表选择并点击“使用方法” |
| 谱图查看 | 打开谱文件：CDT、CMT、WDT、EDT |
| 样品分析 | 打开样品文件：CDT、CMT；方法不唯一时选择确切的已保存旧算法方法，自动适配已编号的完整重复组 |
| 色散曲线 | 打开色散文件：WDT；自动建立已完成的旧谱任务，继续定位、拟合和保存曲线 |
| 蒸发曲线 | 打开蒸发文件：EDT；显示帧峰值、积分随时间的变化 |
| 重新计算 | 打开强度文件：PDT；自动加入并选中来源，继续选择方法版本和曲线快照 |
| 打印与导出 → 分析报告 | 打开报告文件：DAT；直接以当前文件建立报告，无需填写单位 |
| 打印与导出 → 强度数据 | 打开强度文件：PDT；直接预览、Excel/PDF 输出与打印 |
| 样号与样品队列 | 打开样品号：SAM，保存为新版队列 |
| 重新计算 → 旧记录区间查看与 EDT 转换 | 打开蒸发摄谱文件：EDT；选择记录、区间、布局和存储方式后转换 |

桌面版弹出系统文件选择框；浏览器开发模式填写完整文件路径。相关按钮按现有业务与迁移写入权限显示。未编号样品、不匹配的方法或布局仍需核对；DAT未记录单位时保持空值并在报告说明中标注，程序不会猜测或改写旧原件。

需要批量搬迁时，进入工具中的对应迁移页面，使用“批量迁移方法库 / 谱文件 / 结果文件”多选文件。文件逐个校验并保存，失败时显示已完成数量；原有单文件暂存、报告核对和提交功能继续保留。


如果不需要 SpecDirect 旧数据，可跳到第 4 步。

#### 3.1 迁移旧方法和配置

进入“工具 → 旧方法与配置迁移”。

1. 确认“Jet 读取器就绪”。读取器不可用只会阻止旧方法迁移，不影响新建方法和日常分析。
2. 分别输入旧版 `DIRECT.MTD`、`DIRECT.CFG`、`DIRECT.OPT` 的完整路径。
3. 点击“只读暂存并校验”。
4. 检查迁移报告中的方法数、谱线数、色散曲线数、源文件 SHA-256 和全部一致性检查。
5. 确认报告无阻断问题后，点击“原子提交”。

#### 3.2 迁移旧谱数据和旧结果

1. 进入“工具 → 旧谱数据迁移”，选择 CDT、CMT、EDT 或 WDT 文件。
2. 先暂存并检查格式、CCD 布局、记录数、坏帧和源文件指纹，再原子提交。
3. 进入“工具 → 旧结果迁移”，选择 DAT 或 PDT 文件。
4. 检查样品、谱线、矩阵维度、方法匹配状态和源文件指纹，再原子提交。

迁移过程只读取原件并在临时副本中解析，不会回写旧文件。解析失败时不要修改历史原件，应先核对文件来源和迁移报告。

### 第 4 步：连接模拟设备并做实时诊断

进入“工具 → 设备调试 → 调试对中”。

1. 在“待连接设备档案”选择 ACQ 模拟器设备档案。
2. 核对 CCD 布局、点数和保护时间。
3. 点击“连接诊断”，确认适配器状态变为已连接。
4. 选择模拟样本、随机种子和要查看的 CCD。
5. 点击“开始”，观察实时曲线、峰值、峰位、帧序和帧哈希。
6. 可使用十字线、横向放大、缩小、100%、400% 和还原视图。
7. 检查完成后依次点击“停止”和“断开”。

实时调试不会生成样品或谱图记录，界面中的“记录写入”应保持为 `0 样品 · 0 谱图`。

同一入口内另有“软件参数”“设备参数”“汞灯调试”页签：软件参数保存空白传输、观察等待、屏幕换算和分析显示选项；设备参数通过设备档案接口保存串口、CCD 等配置；汞灯调试保留选线、会话、偏移建议及应用/回滚。页面左上角显示“设备调试”图标主标题，参数和调试卡片内使用普通小标题，四页签共用右侧操作区，汞灯会话列表位于左侧，可收起和展开；调试运行及请求处理期间也可切换，草稿和后台调试保持，切回原页签即可继续观察或停止；各项仍按独立权限开放。主题、备份和日志等通用设置仍在“系统管理 → 软件设置”。

### 第 5 步：需要时建立色散校准

如果已有适用的已发布色散校准，可跳到第 6 步。

进入“分析测试 → 色散摄谱”采集数据；完成后进入独立的“分析测试 → 色散曲线”处理。

1. 在建立摄谱页点击右上角“新建任务”，在独立窗口选择设备档案和 CCD 布局。
2. 设置燃烧帧和暗帧数量。
3. 点击窗口底部“新建任务”，进入当前采集页后再点击“试样摄谱”，自动完成本次摄谱。
4. 需要预热时使用独立的“预热摄谱”，完成后仅观察谱图，不制作正式色散曲线；需要时使用“暂停”“继续”或“停止摄谱”安全收尾。
5. 完成或停止当前采集后，进入“分析测试 → 色散曲线”，选择刚采集的任务；在“谱线定位与位置”中输入元素、已知波长和 CCD，点击“添加”。
6. 至少准备 3 个有效定位点，采集到帧后点击“全部定位”，必要时逐项核对位置。
7. 输入校准名称，点击“二次拟合”。
8. 检查有效波段、RMS、最大残差和是否允许发布。
9. 校准可发布时点击“发布版本”。
10. 需要时在“绑定已发布方法修订”中选择方法并点击“绑定修订”。
11. 常用预激发、周期、燃烧与空白次数可点击“保存激发条件”，供下一次色散任务载入；它与蒸发摄谱的默认条件分开，已建立任务不改写。

色散原始帧和已发布校准版本不可原地修改。残差超限时应检查定位点，不要强行把不可发布草稿用于正式方法。

### 第 6 步：新建、配置并保存方法

进入“光谱方法 → 方法管理与参数”。

#### 6.1 新建方法

1. 点击“新建方法”。
2. 输入方法名称并确认。名称要简短，兼容旧格式时应控制在 GB18030 编码 20 字节以内。
3. 在方法列表中选中新方法，完成配置后点击“保存”。

#### 6.2 配置方法条件

在“方法管理与参数”中编辑所选方法：

1. 填写名称和说明。工作类型不再单独编辑，已有兼容值保留。
2. 选择已发布色散曲线，自动带入对应 CCD 布局和已安装的 CCD，无需单独选择或显示布局。已有方法在打开或保存其他参数时保留原 CCD 配置；只有主动选择色散曲线才重新带入。新增谱线仍自动检查检测范围和安全边界。谱板与激发参数并排等高，转角在下方每行两组，“重复与误差”中的误差控制直接显示。
3. 在“转角与存储方式”中添加、修改或移除方法使用的转角，并在同一行选择“区间平均”或“全时保存”；再设置采集帧数、暗帧数、重复次数、预激发及其他激发条件。
4. 按旧版六项设置普通样品、标准样品、管理样重复次数，以及“重复摄谱最大允许误差[^P]”“相对偏差校验”“最大允许Rsd[%]”。关闭校验时停用对应Rsd输入；校准阈值、质控阈值、异常阈值和标准样品名称不在此编辑，已有值保留。
5. 需要逐线选择曝光帧时开启“区间曝光”，至少采集两帧；关闭时使用简单均值。
6. 点击顶部“保存”，一次完成条件校验和新有效版本保存；转角与存储方式一起保存，存储范围自动覆盖全部采集帧，不再填写第二套起止帧。原有历史版本保持。无效输入、重名或版本冲突时本次修改不写入，界面保留输入。

#### 6.3 配置分析谱线和标准点

进入“分析谱线”页签：

1. 添加分析线、内标线、定位线等所需谱线。
2. 为每条谱线设置元素、波长、峰值/拟合参数、单位、有效范围和内标关系。单位可选 `ug/g`、`mg/g`、`%`，切换时同步质量比标准值、有效范围与精度；检查数值后保存。内标使用“背景做内标”或“内标谱线”，坐标使用“对数坐标”勾选。CCD和转角归属由方法及检测结果显示；转角统一在方法参数页配置。
3. 确认界面显示该谱线在当前 CCD 和校准范围内可检测。
4. 对分析线设置标准点名称和标准值。标准点名称必须与后续标准样品的样品名完全对应，例如方法中使用 `S1`，采集的标准样品也应命名为 `S1`。
5. 开启区间曝光后，在编辑区顶部的“谱线曝光区间”中填写该谱线的“曝光起始帧”和“曝光结束帧”，保存每条谱线，直到方法顶部不再显示待修正项。采集存储选择统一在方法页维护，本页只设置逐线计算参数。

#### 6.4 预览、保存并使用方法

1. 进入“预览与打印”，核对方法条件、谱线和标准点。
2. 需要时设置打印机、纸张、方向和版式；边距在高级区。份数、双面、彩色等未接通选项不显示。生成预览或导出方法参数 PDF，隐藏兼容字段在末尾“兼容参数（保留原值）”查看。
3. 返回方法操作栏，确认待修正项为 0。
4. 点击“保存”，系统自动生成可使用且保留历史的版本，无需另行发布。
5. 点击“使用方法”，将所选已保存方法设为当前。已有停用方法也可通过此按钮重新启用。
6. 顶部“当前方法”应显示方法名称和保存后的版本。

修改当前方法后，点击“保存”即更新当前引用，无需再次打开；保存其他方法不会切换当前方法。原任务、原始数据及历史结果继续引用原版本。方法页不再提供暂停/恢复；运行中的采集或分析仍使用各自任务控制。“另存为”复制当前已保存方法，需先保存未提交的修改；删除保留历史版本。

### 第 7 步：建立样品队列

进入“分析测试 → 样号与样品队列”。

1. 点击“新建队列”。
2. 输入队列名称、样品名和重复次数。
3. 点击“创建队列”。
4. 继续输入其他样品，点击“插入样品”。
5. 12位和20位样号统一显示为铺满可用宽度的表格，格宽按所选位数的数字、字母宽度调整，较长中文在格内换行。每列20个位置，先向下填满再进入右侧一列；列数由样号位数和窗口宽度确定，空位置也保留。新增样品只填入下一个格子，不重新分配已有样品；当前页满后用表格上方的翻页按钮查看。
6. 点击样号，在表格下方核对预录名称、重复次数、展开谱带数和采集后名称；删除按钮作用于当前选中的样品。双击格子、选中后按F2或点击“修改样号”可编辑既有预录名称，回车或“保存样号”保存，Esc或“取消修改”放弃。编辑期间不能切换队列、位数或追加样品；失败时保留输入，修正后再保存。已关联采集的样品使用采集后命名，不能更改原预录名称。切换位数或窗口宽度时调整格宽和列数；已有名称超过目标位数时拒绝缩短，保留完整数据。
7. 如果已有旧 `.sam` 文件，可点击“导入 SAM”；导入后仍应核对名称和重复次数。
8. 需要交换队列时可点击“导出 SAM”并选择保存位置。

用于标准曲线的标准样品名称必须与方法分析线中的标准点名称一致。普通未知样品应使用不会与标准点重名的名称。

### 曝光条件的设置位置

在“光谱方法 → 方法管理与参数 → 转角与存储方式”维护整套方法的转角与逐转角存储方式。在“激发与采集”设置预激发、采样周期、总采集帧数及“区间曝光”开关。新建方法默认关闭，按简单均值保存；开启时至少采集两帧，并保存全时数据供逐线提取。

保存方法后，进入“光谱方法 → 分析谱线”，选中谱线，在编辑区顶部的“谱线曝光区间”填写“曝光起始帧”和“曝光结束帧”。帧从1开始，两端均计入，必须位于总采集帧数内且至少连续两帧；未单独指定时使用完整区间。关闭总开关后，这两个输入框停用，已有起止值仍保留但不参与计算。修改后需先保存谱线，再点击方法顶部“保存”，新采集任务才会使用新条件；已采集任务及其方法版本保持。

方法页只选择转角和存储方式，整块“高级采集存储范围”及其起止帧输入已移除。本界面保存时，各转角自动保存1至总采集帧数；分析谱线顶部的曝光区间决定每条谱线计算用哪些帧。修改保存后用于新任务，原任务及其绑定版本保持。样品摄谱按原有存储来源选择使用已发布方法，区间曝光开启时仍保留全时数据，确保逐线计算所需的数据完整。

### 第 8 步：建立并执行样品采集任务

进入“分析测试 → 样品摄谱”。色散、蒸发、样品三个入口先显示“建立摄谱”页面，保留三种摄谱方式切换和各自的任务列表，标题右上角提供“新建任务”。在独立窗口填写条件并创建后，进入当前任务采集页，不自动激发；也可从列表点击“进入摄谱”或“查看谱图”。当前采集页占满窗口，按旧版排列标题、顶部谱线栏、左侧样品表、中间谱图与紧凑工具、右侧样号输入与纵向激发按钮；临时隐藏主导航。重复次数随样号只读带出。右键标题或按Shift+F10打开“任务条件与采后命名”，查看进度、即时测量、采后命名及消息；双击谱图或用菜单“谱图点位与视野”打开读数。关闭侧栏后可从菜单恢复。CCD下拉只切换观察曲线。点击“结束”或菜单“返回任务列表”退出当前窗口；运行或暂停时先停止收尾。各模式的新建草稿在取消、失败和类型切换后保留。色散曲线与蒸发曲线仍有独立菜单入口。

任务运行、暂停或控制请求尚未完成时，先完成或停止当前任务，再切换摄谱方式。暂停保留当前任务，不能用来切换另一种摄谱。只读权限及当前方法前置条件继续生效。

#### 8.1 建立任务

1. 在建立摄谱页选择“样品摄谱”，点击右上角“新建任务”；此窗口固定创建样品任务。
2. 输入任务名称。
3. 选择设备档案和 CCD 布局。
4. 选择正确的已发布方法版本。
5. 选择样品队列和预录样品；不使用队列时填写临时样号并选择样品类型。
6. 标准点样品选择“标准样”，未知样品选择“试样”或“普通样”，空白选择“空样”。
7. 核对保存模式：所选方法的“区间曝光”开关决定平均值或全时原始区间；旧版本未声明新模式时仍保留原有任务选择方式。
8. 默认继承方法的激发条件与分类重复次数；需要时展开“高级采集设置”手动覆盖。模拟样本和种子只在相应模拟调试区域设置。
9. 点击窗口底部“创建任务”，进入当前任务采集页；尚未开始激发。

#### 8.2 执行任务

1. 新建成功会进入当前任务；查看已有任务时，在建立页列表点击“进入摄谱”或“查看谱图”。
2. 核对样号、重复次数和当前装样状态。
3. 点击“试样摄谱”后自动完成本次摄谱；每次完成后等待人工确认，重新装样后再点一次进行下一次重复。“预热摄谱”独立执行，不消耗正式重复次数、不生成正式分析谱带。
4. 观察实时CCD曲线与运行阶段；需要详细进度、燃烧帧/暗帧数量及帧哈希时，从标题右键菜单打开任务详情。
5. 需要中断检查时使用“暂停”，确认后点“继续”。
6. 发生异常时使用停止按钮进行安全收尾，不要强制结束后端进程。
7. 等待任务状态变为“已完成”，并确认“结果”为“已收尾”。
8. 如果任务使用临时样号，右键标题打开“任务条件与采后命名”，再展开“采集后重命名”，选择12/20位，输入正式样号并点击“保存名称”。失败时保留输入，保存期间禁止重复提交和换任务。
9. 查看“全部采集消息”，确认没有未处理的错误或警告。
10. 使用预录样品时，可直接在右侧“样品编号”下拉中选择同队列待测项，重复次数自动带出。首次选择待测项会按当前任务条件建立对应草稿，再次选择会复用该任务；确认装样后手动点击“试样摄谱”。当前项完成后仍会提示下一项或队尾，也可通过“下一样品”窗口核对条件。不会自动激发整条队列。

右侧第一个输入图标打开“预录样号”，选择或编辑队列后点击“使用此样号表”，即可回到工作台直接选样。保存期间不能关闭窗口或用Escape离开；失败保留输入。第三个清扫图标只清除待测选择，须重新选择后才能激发，不删除样品。

同一个标准样或未知样需要重复测量时，应让重复次数来自队列或任务设置，不要把一次未完成任务当作完整重复组。

#### 8.3 蒸发摄谱实验

进入“分析测试 → 蒸发摄谱”，在建立摄谱页点击右上角“新建任务”，打开独立条件窗口。本页“保存激发条件”保存自己的预激发、周期、燃烧和空白次数，下次重新载入，与色散默认条件互不覆盖。输入任务名称，选择设备档案和 CCD 布局，设置燃烧帧、暗帧、倒计时、预激发与采样周期后创建任务。每次实验固定单次采集并保存完整时间序列，无需选择样品队列或重复次数。

选中实验，点击共用控制区的“试样摄谱”，自动完成本次完整采集；“预热摄谱”独立执行，只供观察，不保存正式实验谱带。按需暂停、继续或停止摄谱。摄谱页显示实时谱图及进度，手工区间命名、起止帧和“标记区间”已移除；完整时间序列仍按原设置保存。完成后右键标题打开“任务条件与采后命名”，再展开“实验重命名”保存名称。已有蒸发记录显示在蒸发模式，样品记录显示在样品模式。进入这两种摄谱模式仍需先选择有效的当前方法。

查看已保存的数据时，进入独立的“分析测试 → 蒸发曲线”，选择实验及CCD，在“曲线数据”中切换帧峰值或帧积分。横轴为实际采集时间（秒），表格列出对应帧和数值；查看不写入业务数据，损坏帧不参与绘图，读取失败会清空旧曲线并提示。这里显示的是整块CCD的帧峰值/积分，不能等同于旧版逐分析谱线的蒸发强度曲线。已有旧EDT/CMT的临时区间查看和转换从“数据处理 → 重新计算”的折叠工具进入。

### 第 9 步：查看采集谱图

进入“分析测试 → 谱图查看”。

1. 点击“刷新”，选择刚完成的谱图记录。
2. 可勾选 1 至 8 个原始样品进行叠加。
3. 选择转角、CCD 或谱线，使用“上一条/下一条”切换。
4. 使用十字线、滚动、框选、横向/纵向缩放检查峰位和强度。
5. 需要定位时输入波长，或用 `2,123` 定位到第2块CCD的第123点。图内左右方向键逐点移动，上下方向键缩放；CCD与点号显示从1开始。
6. 全时数据可设置曝光区间，也可读取指定 burn/dark 原始帧。
7. 导出前确认样品、转角、CCD、曝光区间和当前可见范围。
8. 多样叠加时点击同一点位，检查逐样“同点强度”表。
9. 选点后打开“查看分时明细”，检查全部燃烧/空白原值以及预激发、周期和次数；可按横纵格式复制或输出PDF。没有保存完整帧的记录不能恢复原始分时值。
10. 点击“导出可见范围”保存当前数据，或输出当前视图PDF。使用“打印CCD”时可选当前CCD/图像、灰度/峰形图层及宽边/窄边/十倍CCD比例；至少选一个图层。十倍CCD按物理点距计算，A4放不下时须换合适纸型，例如A3。生成PDF不等于实体打印机已出纸。

“参考校正”只影响当前查看和输出口径；需要形成正式校准时应回到色散校准流程。分析页的“谱图”选中谱线后，会按该线固化的曝光区间重建观察谱带，并显示当前区间，便于与定量取段核对。查看不会改写历史分析结果。

### 第 10 步：执行定量分析和慢进复核

进入“分析测试 → 样品分析”，展开“建立分析运行”。

1. 输入分析批次名称。
2. 选择计算档案：
   - `modern_v1`：现代高斯面积定量。
   - `legacy_2_0_2`：旧版峰高计算口径。
3. 根据需要启用“逐谱线慢进”，并设置慢进超时。
4. 勾选已完成采集的样品。同一批次只能使用同一个方法版本的样品。
5. 点击“建立并锁定输入”。
6. 点击“开始”。
7. 如果启用了慢进，出现检查点时查看峰位周边谱图：
   - 自动峰位正确：可保持当前峰位并点击“接受调整”。
   - 需要人工修正：输入调整后峰位和理由，再点击“接受调整”。
   - 不采用人工调整：点击“放弃调整”，系统使用自动定位结果。
8. 点击“推进一条谱线”，重复处理后续检查点，直到分析状态为“已完成”。
9. 在“谱图与测量”检查峰位、峰高、背景、Sigma、面积和定量信号。

人工峰位调整、理由、输入哈希和最终结果都会写入审计记录。

### 第 11 步：完成重复质控、标准曲线和结果合并

继续在“样品分析”中操作，共用当前批次与谱线，无需切换其他菜单。标准曲线、标准点及样品结果是同一工作区的查看方式，右侧重复性检查保持可用。管理样适配、标准强度修正、对数坐标、四种拟合及图像/文本输出保留。

#### 11.1 重复质控

1. 分析完成后会自动进入同一工作区复核；右侧“重复性检查”直接显示当前谱线的统计，按需选择检查样品。
2. 查看均值、极差、标准差、RSD、ID 和有效次数。
3. 有警告时，先检查各次重复值。
4. 可以“接受提示”，也可以剔除明显异常重复；误剔除时点击“恢复”。
5. 点击“重新统计”，确认质控快照显示“可用于拟合”。

#### 11.2 标准点和曲线

1. 打开“标准点”视图，确认每个标准点都找到了同名标准样品并显示原始强度。
2. 必要时停用异常标准点，或保存修正强度；所有修正都需要留下明确理由。
3. 打开“曲线图”视图。
4. 选择拟合方式：直线、二次、三次或样条。
5. 用“对数坐标”复选框切换坐标；分析单位沿用谱线设置，百分含量的曲线刻度及下游结果保持一致。
6. 点击“重新拟合”。
7. 检查相关系数、RMSE、标准点反算值、相对误差[%]及曲线是否可发布；文本预览与PDF也显示反算和相对误差。
8. 可使用图像预览、文本预览或打印 PDF 复核。
9. 需要微调时，在曲线图选择标准点，用标尺1/5及上下按钮，或Ctrl＋上下调整强度；Ctrl＋左右选点，Insert切标尺。修改后旧拟合标为过期，必须重新拟合再打印或发布。
10. 确认后点击“保存曲线”（内部仍生成有效的不可变版本），再点击“下一条谱线”。左侧可随时返回已处理谱线；修改质控或标准强度后须重新拟合、保存。

#### 11.3 合并样品结果

1. 最后一条曲线保存后，点击“完成并保存结果”，自动合并并显示“样品结果”；也可以在页内切换查看。
2. 确认所有分析谱线都已有已发布曲线快照。
3. 检查样品的有效次数、均值强度、分析值和单位。
4. 如需再次保存当前合并结果，可点击“合并并保存”。
5. 记录合并快照编号和结果哈希。报告应使用这个最终合并结果。

### 第 12 步：需要时重新计算或输出强度数据

“数据处理”保留“重新计算”和“打印与导出”两个入口。“打印与导出”只有“分析报告”和“强度数据”两个页签。

1. 输出新版强度时，进入“打印与导出 → 强度数据”，选择已完成的分析批次，即可保存强度文件、输出文本或打印逐样品、逐重复的峰值/背景强度表。不需要先导入或查看旧PDT。
2. 旧软件文件先通过“工具 → 旧结果迁移”导入；独立旧PDT强度表卡片已移除。需要输出已迁移结果时，展开“重算与已迁移结果导出”并选择相应来源。
3. 需要重算时进入“重新计算”，选择源记录、确切方法版本、计算档案及已发布曲线快照；原结果保留。完成后返回强度页，展开辅助区，选择该重算批次与TXT、CSV或Excel格式导出。
4. 旧记录的临时区间查看和EDT转换保留在“重新计算 → 旧记录区间查看与EDT转换”中；展开后可选择CCD、取样区间和转换存储方式。这不修改分析谱线已设置的曝光区间。
5. 全时数据导出界面及其均值附加选项已按用户要求移除；方法中的平均值/全区间保存、谱线曝光区间及原始数据保留。
6. 两个输出页签及重算入口之间切换会保留输入和选择；离开数据处理工作区后按原规则重新加载。

任一来源记录失败时不要拆分绕过，应先处理阻断原因，确保整批版本绑定一致。

### 第 13 步：建立、预览、确认和导出报告

进入“数据处理 → 打印与导出 → 分析报告”。

1. 输出分析结果时，先在“分析测试 → 样品分析”打开已完成并保存合并结果的批次，再进入报告页；当前批次会自动带入。输出旧 DAT 时，点击标题栏右侧“打开报告文件”，每次只使用打开的这一份文件，无需填写单位；新报告保留原数值，未记录的单位留空并作说明。
2. 可填写报告编号；留空时由系统生成。
3. 选择报告模板。
4. 选择“常规排列”或“交换排列”。
5. 需要时填写样品筛选和元素筛选。
6. 点击“建立报告版本”。
7. 刚建立的草稿会自动选中；报告版本列表仍可打开已有报告。
8. 点击“预览”，核对样品、元素、方法版本、计算档案、质控状态和结果。
9. 关闭预览后点击“确认报告”。确认后才能作为正式输出来源。
10. 点击“Excel”或“PDF”，在保存窗口选择位置；需要纸面输出时选择 Windows 打印机后点击“打印”。
11. 根据页面提示确认保存或打印结果。打开另一份数据会替换当前来源；取消或打开失败保留当前数据和填写内容。

同名输出采用自动加后缀策略，不会静默覆盖已有报告。

### 第 14 步：备份、审计和退出

#### 14.1 创建并校验备份

进入“系统管理 → 备份与维护”。

1. 确认数据库状态为“数据库正常”，外键错误为 0。
2. 输入项目主文件夹之外的备份目录。
3. 点击“创建备份”。
4. 在备份记录中点击“校验”。
5. 需要回收空闲空间时，先备份，再点击“整理数据库”。
6. 清理历史日志时填写“保留天数”，再点击“清理记录文件”；当前日志和审计记录保留。
7. 管理员排查问题时展开“系统诊断”，再点击“刷新诊断”。

不要在软件运行时直接复制 SQLite 主数据库来代替在线备份。

#### 14.2 检查审计

进入“系统管理 → 审计记录”，检查登录、用户权限、方法、采集、分析、曲线、报告和维护操作是否有完整记录。

#### 14.3 正常退出

1. 先停止正在运行的实时调试、采集或校准任务。
2. 等待任务完成或完成安全停止。
3. 点击窗口右上角关闭按钮。
4. 主窗口关闭后，后端进程会自动退出。

## 四、日常分析的最短操作顺序

首次设置和方法发布完成后，日常操作可以按以下顺序进行：

1. 启动 `GeoSpectrum.exe` 并登录。
2. 在工作台确认本地服务在线、当前方法正确且未暂停。
3. 建立或选择样品队列。
4. 为标准样和未知样分别建立采集任务并完成全部重复采集。
5. 在谱图查看中快速检查峰位、异常曲线和样品名称。
6. 建立分析运行，完成慢进检查点。
7. 完成重复质控。
8. 检查标准点、重新拟合并发布每条标准曲线。
9. 在样品结果中“合并并保存”。
10. 建立报告、预览、确认并导出。
11. 创建在线备份并正常关闭软件。

## 五、常见问题处理

### 1. 双击后没有窗口

- 确认 `GeoSpectrum.exe` 和 `geospectrum-backend.exe` 位于同一文件夹。
- 不要从压缩包内部直接运行。
- 检查 Windows 安全软件是否隔离了后端 EXE。
- 等待数秒后再试；单实例机制不会同时打开多个主窗口。

### 2. 显示本地服务离线

- 关闭主窗口后重新启动，不要单独启动后端。
- 检查后端文件是否被改名、移动或删除。
- 查看工作台运行消息中的错误码；管理员可在“备份与维护 → 系统诊断”查看详细状态。

### 3. 菜单灰色或不能进入

- 先发布一个有效方法并点击“设为当前”。
- 如果当前方法已暂停，进入方法管理点击恢复。
- 如果入口完全不可见，请让管理员在“用户与权限”中授予所需最小角色或权限。

### 4. 标准曲线无法拟合或发布

- 确认分析已完成并生成质控快照。
- 确认标准样品类型为“标准样”。
- 确认标准样品名称与方法标准点名称完全一致。
- 确认每个启用标准点都有有效重复均值。
- 检查被剔除重复、RSD 警告、拟合点数和残差。

### 5. 报告列表为空或不能输出

- 确认分析运行状态为“已完成”。
- 确认每条分析谱线已发布曲线快照。
- 确认已执行“合并并保存”。
- 报告草稿应先预览并“确认报告”。
- 输出目录必须已经存在，并且当前 Windows 用户具有写入权限。

### 6. 忘记管理员密码

软件没有默认密码，也不应通过删除 `%LOCALAPPDATA%\cn.geospectrum.desktop` 来重置，因为这会丢失本机业务数据。应联系已有管理员账户处理，或从已验证备份制定恢复方案。

### 7. 真实转角或汞灯功能

当前界面会显示“需真实设备”或外部门禁状态。缺少现场协议和硬件验收时，不要尝试猜测串口命令、绕过安全状态机或把模拟器结果写成真实硬件结论。

## 六、文件和数据保护原则

- 前后端 EXE 必须成对保留，升级时也必须使用同一次构建的两个文件。
- 旧版 MTD、CFG、OPT、CDT、CMT、EDT、WDT、DAT、PDT 和 SAM 原件保持只读，不要用新版程序覆盖。
- 方法发布版本、校准版本、质控快照、曲线快照和报告版本都是可追溯记录，不要用人工修改数据库代替业务操作。
- 使用“备份与维护”中的在线备份及校验，不要把手工复制数据库当作完整备份流程；实际恢复由维护人员在保留现库后处理。
- 出现错误时先记录错误码、任务编号、时间和运行消息，再决定重试、恢复或重新采集。
