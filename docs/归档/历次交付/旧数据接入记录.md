# 旧数据接入记录

以下为 2026-10-19 测试库快照。当前操作见 [使用说明](../../使用与说明/GeoSpectrum_使用说明.md)。

## 七、本机已准备的旧数据测试入口（2026-10-19）

本批已写入当前Windows用户的正式数据目录，打开项目主目录程序后点各页“刷新”，或退出重开即可。此前该库没有分析运行和报告，旧谱图导入后还需要选择兼容方法、完成测量、曲线及合并，才能作为报告来源。本次保留了原有记录，并通过这些业务操作准备样例；测试名称统一以“旧数据测试”开头。

| 要测试的功能 | 入口与选择 | 已有数据及操作结果 |
|---|---|---|
| 分析运行、报告 | 分析测试 → 样品分析打开“旧数据测试｜01”或“02”，再进入数据处理 → 打印与导出 → 分析报告 | 当前批次自动带入，建立版本后预览、确认及Excel/PDF输出；也可直接选已有“旧数据测试-01-CMT”报告 |
| 逐线测量与结果 | 分析测试 → 样品分析 → 左侧选择“旧数据测试｜01”或“02” | 两条完成批次各有3个真实旧样品、3个分析元素；使用原方法已有标准强度拟合并保存曲线，已有合并结果 |
| 重复性质控、标准曲线 | 样品分析 → “旧数据测试｜04 CMT 标准样三次重复与曲线” | 包含3个普通样品和10个标准样的三次重复，共33条测量输入；S0–S9按旧版规则映射为S1–S10。存在原计算产生的重复性超限提示，全部重复和提示保持，未自动剔除或接受。可练习复核、删除/恢复重复、拟合和保存；修改质控后须重新拟合、保存曲线并合并 |
| 从头操作慢进分析 | 样品分析 → “旧数据测试｜03 CMT 慢进逐线分析（待开始）” | 草稿保留3个旧样品；点开始后逐线复核与继续，可练习人工定位、接受/放弃和最终结果保存 |
| 样号与分页 | 分析测试 → 样号与样品队列 | 选择“旧数据测试｜测试15-5”100项或“旧数据测试｜测试15-5-960”800项；连同原有7项，当前库共907项。大文件名称含960，但实际SAM解析为800个样品项 |

| 强度输出 | 数据处理 → 打印与导出 → 强度数据 | 分析批次选择“旧数据测试｜01”或“02”，可查看峰值/背景并预览、输出Excel/PDF |
| 重新计算 | 数据处理 → 重新计算 | 旧PDT和已适配采集样品均已接入，已有1条使用固定方法/曲线快照的成功重算记录。方法选“测试15-5”v1，选择同版本来源及曲线；本批测试显式记录了允许晚于测量时间的方法确认 |

样例用于操作、兼容性和软件流程演练，真实样品结果仍须按实验室方法和质控要求复核。尤其04批次保留了超限状态，不能因为已生成测试报告就当作已通过实验室质量审核。

36份源文件的大小、修改时间和SHA-256已复核保持；分类目录SpecFile的重复副本没有重复导入。可读的24份正式格式源中20份已接入（含已有记录复用），另外4份因原始BLOB结构不合规而未强制导入：方成DIRECT.MTD、化验DIRECT.MTD、标准系列.wdt、标准系列S10.wdt。QCT/QCT_尚不在已确认支持格式中，原件保留；不得改扩展名冒充WDT/EDT。明细见[旧数据接入验证](../../acceptance-reports/S24/artifacts/2026-10-19-legacy-data/verification.json)与[未导入文件](../../acceptance-reports/S24/artifacts/2026-10-19-legacy-data/rejected-files.json)。
