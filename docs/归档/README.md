## 本机归档

`docs/归档/本机资料/` 收纳原根目录的合同功能要求图片、`SpecDirect-Simulation.exe` 和 `StandaloneMotorApi/` 独立电机服务工作副本。该目录按本机资料忽略规则保存。原根目录 `.local/` 的源码压缩备份和 pytest 历史输出归入 `app/.local/backups/2026-11-26-root-local/`。

## 旧版规则与格式依据

- [S00 事实与黄金样本](../acceptance-reports/S00/baseline/README.md)：旧格式、算法、受控输入哈希与历史工具。
- 本机可读 [旧版功能树](../../Spec2.02功能研究/01_功能树_源码整理版.md)，定位后再回查 Delphi 源码及 `.dfm`。
- [旧 Delphi 源码](../../Spec%20Source/)、[分类来源索引](../../SpecFile/README.md) 与 [文件来源清单](../../SpecFile/文件来源清单.csv)。
- 现存运行原件另查 `Spec Source/Bin/`，归档夹具位于 `app/tests/fixtures/legacy_runtime/`，按各自源哈希区分；旧资料目录始终保持只读。
- 分步原始验收结论与证据产物保留在 [acceptance-reports/README.md](../acceptance-reports/README.md) 及 `docs/acceptance-reports/S00`–`S24/`，不随文档归并改写。

## 文档维护规则

- 根 README 保持启动和查阅入口。`docs/README.md` 只提供文档导航。最新交付、验收状态和对应证据更新在 `acceptance-reports/README.md`。独立操作手册由 `使用与说明/GeoSpectrum_使用说明.md` 生成。
- 阶段结论、历史研究快照和过时演进记录统一沉淀到 `docs/归档/`，不在文档首页逐条堆积流水账。
- 原始验收报告（`docs/acceptance-reports/`，含归并后的 `S00/baseline/` 黄金样本）路径保持稳定，确保脚本与历史证据可追溯。
- 临时输出、测试日志、排查截图与本地释放副本统一放入系统临时目录或 `app/.local/`，不留在 `docs/` 或项目根目录。
