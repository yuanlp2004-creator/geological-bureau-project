# GeoSpectrum 前端视觉系统统一与体验精修清单

> 本文档面向 `GeoSpectrum.exe` 对应的前端工程（`app/frontend/src/`），整理当前界面的主要审美与交互问题，并给出可直接交付 `gpt6.2sol` 执行的修改规范、目标效果与验收清单。

---

## 1. 目标定位、执行红线与分阶段策略

### 1.1 目标视觉定位

**现代精密科学仪器桌面端（Modern Precision Scientific Instrument）**：
- 冷静、克制、高信息密度但层次分明、实验室长时间盯屏舒适；
- 彻底消除“现代极简外框 + 千禧年高饱和荧光原色内核”的时代撕裂感；
- **保留老用户对谱图蓝灰底板和核心操作区位的肌肉记忆**，用低饱和现代科学色阶转译旧版界面。

### 1.2 修改范围与红线（务必遵守）

1. **修改范围**：仅修改 `app/frontend/src/` 下的前端样式与展示层组件。
2. **禁止触碰目录**：严禁修改 `Spec Source/`、`Spec2.02/`、`SpecFile/`、`UI测试/`，以及后端代码、数据库 schema 和 API 契约。
3. **功能零回归**：所有现有业务功能、按钮动作、框选缩放、平移、十字线读数、右键菜单、表单校验、剪贴板批量粘贴、窗口最小化/最大化响应式布局均须完整保留，既有前端测试与构建必须全部通过。
4. **深色模式同步**：凡涉及 `:root[data-theme='dark']` 的样式覆盖，须同步映射到统一后的令牌变量，避免硬编码色值破坏暗色对比度。

### 1.3 建议分三阶段执行

| 阶段 | 包含模块 | 核心目标 |
| --- | --- | --- |
| **阶段 1** | **M1 + M2** | 收口 Design Tokens，彻底解决核心谱图工作台的荧光撞色与年代撕裂感 |
| **阶段 2** | **M3 + M4 + M5** | 主框架壳层瘦身、图标两层体系统一、按钮主次权重与仪器控制区安全层级 |
| **阶段 3** | **M6 + M7 + M8** | 表单/表格/窄栏精致度修复、工作台首页重构、工程残留清零 |

每阶段完成后构建前端，并分别在 **1060px（窄窗）、1440×900（常规）、1920×1080（宽屏）** 下截图核对。

## 2. 现状核心问题速览

1. **时代撕裂**：深海蓝侧栏与浅灰蓝画布走现代风，但谱图工作台、调试对中内部仍保留 `#70e3e8` / `#00ffff` 荧光青底配 `#be2424` / `#c41616` 鲜红字、纯平 `#a8c9eb` 底板与 `#f12222` 鲜红线。
2. **图标体系割裂**：同屏混用 `lucide-react` 细线单色图标、高饱和重绘 PNG、按钮内强行混搭红球加号/黄扫帚 PNG；侧边栏一级菜单（宽 `246px`）纯文字无图标，显空旷。
3. **壳层套娃与信息冗余**：顶部最多堆叠 5–6 层水平条（顶栏、快捷栏、页头、谱线栏、观察工具栏等）挤压谱图视野；「当前方法」在顶栏与侧栏重复两次；「工作台」首页系统状态重复展示 3 遍且缺高频实验流入口。
4. **层级与细节失衡**：分析谱线一屏并存 4 个同等权重蓝实心主按钮；摄谱控制按钮间距松散且缺少危险急停语义；宽屏输入框过度拉伸、数值框孤立右贴边；`定位谱线` 过窄截断；谱图查看左栏浓度提示出现孤字换行；存在 `LOCAL SIGN IN`、`detectable` 等工程残留。
5. **底层样式债**：48 份 CSS 共 12,608 行，含 1,229 处硬编码色值、1,475 处 `:root .app-shell` 提权覆盖和 47 处 `!important`，导致主蓝（4 种）、圆角（6 种）、控件高度（7 档）全站分裂。

### M4. 图标体系分层统一（消除“贴纸混搭感”）

**涉及文件**：
- `app/frontend/src/components/FunctionIcon.tsx`
- `app/frontend/src/pages/sampleQueues/SampleQueuePage.tsx` / `SampleNumberTable.tsx`
- 涉及通用按钮或页头混用 PNG 图标的页面组件

**具体修改**：
建立**“两层图标分工规则”**，禁止越界混用：
1. **第一层（常规 UI 动作、导航、表单、弹窗、页签按钮、页头图标）**：**100% 使用 `lucide-react` 统一线宽（`strokeWidth={1.75}`）单色图标**：
   - 清理按钮内违和混搭：如「预录样号」弹窗蓝色主按钮「插入样品」中的红底白加号 PNG → 改为白色 `Plus` 线框图标；清除按钮的黄色拟物扫帚 PNG → 改为中性 `Eraser` 或 `Trash2` 图标（悬停变危险红）。
   - 页头方框图标（`.app-page-heading-icon`）统一采用浅蓝柔底（`var(--ds-primary-soft)`）+ `var(--ds-primary)` 单色线框图标（`20px`），消除页头中彩色 PNG 与线框图标混出现象。
2. **第二层（谱图工作台专属观察工具栏：1:1、1:4、10×、框选、平移、十字线、校线等专业图标）**：
   - 保留重绘专业图标，规范按钮壳体：默认态统一 `26×26px` 透明底；悬停态 `var(--ds-primary-soft)`；激活态（`aria-pressed="true"`）浅蓝底 + `1px solid var(--ds-primary)` 边框；禁用态统一 `opacity: 0.35; filter: grayscale(0.8)`（避免禁用图标仍然色彩艳丽干扰视线）。

**形成效果**：
- 常规业务页面全线统一、干净克制；谱图专业工具栏保持高辨识度且状态态清晰。

2. **摄谱工作台右侧控制区建立“仪器实体感 + 安全层级”**：

**形成效果**：
- 任意界面第一眼即可锁定主动作；摄谱控制面板具备精密仪器的稳重手感与急停安全辨识度。
