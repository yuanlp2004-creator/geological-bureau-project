## 3. 按功能域整理的生效改动清单（Before → After）

### 3.1 前端状态层解耦与渲染隔离
- **改造前**：每 `1.5s` 日志轮询与设备状态直接触发顶层 `WorkspaceApp` 重渲染，波及主工作区与谱图组件；切页丢失当前选定谱图/方法/曲线/重算上下文，离页未保存草稿易丢失，并发硬件操作与 850ms 调试轮询存在竞态/离页泄漏隐患。
- **改造后**：基于 React 19 原生 `useSyncExternalStore` 新增 6 套框架无关纯核心 + Store：
  - **`runtimeEventsStore`**：单在途轮询、`generation` 防旧包、ES2020 指纹去重；15.5s 静置 11 次轮询下 `WorkspaceApp / SpectrumPlot / MessagePanel` 增量渲染均实测为 `0 / 0 / 0`，注入新消息仅 `MessagePanel +1`。
  - **`themeStore`**：以 `geospectrum:theme:${userId}` 按用户独立记忆浅/深色主题，冷启动首帧防白闪。
  - **`deviceStatusStore`**：受 `devices.read` 门禁保护的零轮询展示镜像，5.5s 静置请求增量为 `0`。
  - **`shellLayoutStore`**：按 `user.id` 记忆侧栏展开/折叠态，支持 `Ctrl+Shift+F` 专注模式与双状态精准还原。
  - **`workbenchStore` + `workbenchRestore` + `navigationGuard`**：跨页往返恢复严格零写请求（`writeCalls === 0`）、防异步乱序覆写、删项优雅回退、外部明确跳转优先、未编辑过的服务端 `draft` 不误报脏态。
  - **`hardwareLockStore`**：UI 操作令牌在首个 `await` 前同步获取，经 `active_captures` 对账自愈 `'unknown'` 未知态；保留「同档案 `connected_idle` 空闲串口交接给采集」及「转角切换期间停止/断开可用与抢占」契约；`AcquisitionPage` 离页 `2.1s` 内 `stepDeviceDebug` 泄漏实测为 `0`。

### 3.2 Canvas 2D + 透明 SVG 混合高频谱图引擎
- **改造前**：`SpectrumPlot` 与 `AlignmentMonitor` 使用全量 SVG 渲染曲线与网格，多曲线高点位叠加时节点庞大、交互卡顿。
- **改造后**：
  - [canvasSpectrumRenderer.ts](../../../../app/frontend/src/components/canvasSpectrumRenderer.ts) 实现底层 Canvas 2D 冻结背景/网格/曲线绘制 + 上层透明 SVG 命中与标注层（彻底移除 `.spectrum-line` / `.spectrum-single-point` / `.plot-grid` SVG 回退）。
  - 集成像素桶 Min-Max 降采样（保留极值顺序、首尾端点与单点峰）、首点优先 `O(log N)` 光标二分检索、`datumIndex` `O(1)` 方向键步进、DPR/`dppx` 与明暗 CSS 令牌自适应监听；独立 `AlignmentMonitor` 同步迁移，确保切角或串口失败时立即清空画布且迟到旧角帧不重画。
  - **实测性能**：单曲线（2,048 点）交互均值耗时由 **`65.23ms` 降至 `8.90ms`**，P95 由 **`362.50ms` 降至 `8.10ms`**；浏览器实测合成 `30 曲线 × 4,096 点`（`122,880` 点）`renderSpectrumCanvas` 绘制均值 **`4.48ms`**（P95 `6.70ms`，最大 `6.80ms`）；光标命中误差 **`0` 点**，PDF `print_scope='visible'` 导出跨度（`5.5114`）精确匹配。

### 3.3 桌面外壳重构与多分辨率排版
- **改造前**：顶部占高偏大、方法切换耦合；侧栏固定不可折叠，无专注模式；底部消息区折叠态占用明显垂直空间且缺乏未读告警提醒。
- **改造后**：
  - **紧凑顶栏与快捷栏**：`.topbar` 收紧至 `40px`，8 枚快捷按钮保持单行且底边 `76px ≤ 100px`；右上角方法区拆分为非嵌套兄弟双键 `.workspace-method-split`（左 `.workspace-method` 受 `methods.read` 保护跳转方法页，右 `.workspace-method-switch` 受 `methods.write` 保护调用共用 `OpenMethodDialog`），全窗口齐平 `32px`。在 `1060×680`（`844px` 主区）覆盖 23 个入口全部实现单行标题零折行与 `0px` 横向溢出。
  - **Icon Rail 与专注模式**：侧栏保留 `216px` 默认展开态，支持手动切换至 `56px` 图标轨（含键盘方向键/`Esc` 与飞出菜单）及 `Ctrl+Shift+F` 专注模式。
  - **`28px` 纤细底栏**：展示连接/模拟设备状态摘要及基于 `lastSeenEventId` 的独立未读告警/错误徽标，同时完整保留 `AnalysisPage` `information` 联动及消息抽屉展开/过滤/清屏交互。

### 3.4 摄谱工作台、样号键盘流与可追溯语义着色
- **样品摄谱工作台**：[spectroscopyStatus.ts](../../../../app/frontend/src/pages/acquisition/spectroscopyStatus.ts) 统一 14 种运行状态，将状态胶囊与多转角页签内嵌进 `.legacy-window-caption`；燃弧/预热期 `captureLocked` 下停止键不抢焦点；三栏底边保持 `0px` 对齐；`1060×680` 双转角五键保持 `commandsOverflow: false`。
- **样号高效录入与可追溯色标**：区分 `SampleNumberTable` 列优先与 `AnalysisSampleNamesDialog` 行优先键盘流，实现写后推进/500 失败停原格保留错误、真实 Chromium CDP IME 组合防误提交与上屏提交、`Ctrl+D` 同批次 `spectrum_hash` 拦截与无数字后缀拒绝写空；[sampleSemanticRole.ts](../../../../app/frontend/src/components/sampleSemanticRole.ts) 以可追溯来源实现标准样（冷青）与显式管理任务样（暖琥珀）着色，经 `D13-4` 正反对照验证，队列与编排分支不会误标。

### 3.5 标准曲线质控与谱线库检索升级
- **标准曲线质控与暗室收口**：[standardCurveModel.ts](../../../../app/frontend/src/pages/analysis/standardCurveModel.ts) 与 [CurveResiduals.tsx](../../../../app/frontend/src/pages/analysis/CurveResiduals.tsx) 在样品分析与重算页面提供顶部只读 KPI 胶囊（`相关系数 R`、严禁误标 `R²`、`有效点数 active/total`、`最大相对误差`、`待拟合` 徽标与同曲线同坐标系下的 `ΔR`）、相对误差阈值着色、表图双向悬浮高亮（0 写入）、`canToggleCurvePoint` 逐点开关及默认折叠残差分布图；全面消除深色模式下曲线区白画布与浅蓝条，统一为 `#172638` 深海蓝暗室风格。
- **谱线库二栏检索与 CCD 覆盖带**：[spectralLineFilters.ts](../../../../app/frontend/src/pages/methods/spectralLineFilters.ts) 与 [SpectralCcdCoverage.tsx](../../../../app/frontend/src/pages/methods/SpectralCcdCoverage.tsx) 提供关键字 + 4 类谱线 + CCD + 转角 + 未检出/停用状态筛选、稳定 ID 定位、只读多选批量预览（严格遵守后端补丁限制，0 批量 PATCH）以及顶部 CCD 波段覆盖带（多角方法专设「未确定角位」定位卡），全分辨率下双栏顶边 `yDiff = 0` 且编辑区宽度超过列表区 `1.7×`。
