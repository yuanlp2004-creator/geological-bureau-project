# GeoSpectrum 项目阅读指南

准备实现或验收前，按 [AGENTS.md](../../AGENTS.md) 阅读 [总体计划](../../PLAN.md) 的第 1、3、5 章、第 6 章对应步骤及相关章节，再查 [当前交付与验收](../acceptance-reports/README.md)。开发启动和构建命令见 [应用开发说明](../../app/README.md)。

| 任务 | 从这里开始 |
|---|---|
| 找一个菜单或按钮 | 从 [模块清单](../../app/backend/modules/manifest.py) 找导航键，再查 [navigation.ts](../../app/frontend/src/navigation.ts) 和 [WorkspaceApp.tsx](../../app/frontend/src/layout/WorkspaceApp.tsx) 的页面分派 |
| 追踪保存字段、权限或数据来源 | 从页面调用的 `api/<业务>.ts` 追到 FastAPI 路由、Pydantic 契约、应用服务、SQLite 迁移和对应测试。 [数据库与 API 装配](20_数据库与API装配.md) |
| 排查主题、导航、跨页恢复和谱图 | 先看 `layout/`、`stores/` 和 `SpectrumPlot.tsx`。 [前端架构导读](19_前端架构.md) |
| 核对文件格式和旧版操作 | 先确认旧版实际行为或数据，再回溯 Delphi 源码、DFM 与协议原件。 [旧版证据入口](../归档/README.md#旧版规则与格式依据) |
| 核对串口、电机与对中 | 从设备模块和现行对中流程着手，现场配置和设备指标见对应硬件文档。 [硬件与电机](../硬件与电机/README.md) · [S14 验收](../acceptance-reports/S14/验收报告.md) |
| 排查启动、退出和冻结包 | 查看 Tauri 进程管理、Python sidecar 装配及数据库升级。 [Tauri 和发布链](21_Tauri与发布链.md) |

具体功能按 [模块索引](README.md#18-个正式模块) 查入口、主流程和契约。
