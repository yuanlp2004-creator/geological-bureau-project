1. `python app/tests/seed_bf02_browser.py <新的隔离目录>`，以该目录为进程级 `SPECTRUM_DATA_DIR` 启动根目录 EXE，并临时启用 WebView2 CDP；必须先确认没有其他运行实例。
2. 配置 `PLAYWRIGHT_MODULE`、`QA_CDP`，执行 `node app/tests/bf02_browser_regression.mjs`：退出码 0。
3. 配置 `QA_SWEEP_OUTPUT` 指向隔离目录 JSON，执行 `node app/tests/desktop_click_sweep.mjs`：最终退出码 0。
4. 本次原始结果：隔离目录中的 `sweep.json`（首轮定位错误）、`sweep-final.json`（最终通过）。
