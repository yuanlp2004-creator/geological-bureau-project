## 3. 按功能域整理的最终生效改动清单（Before → After）

### 3.1 统一设计令牌与科学谱图双主题色板
- **改造前**：48 份 CSS 中硬编码色值分散，主品牌蓝 4 种并存；样品分析、谱图查看、色散曲线、蒸发曲线、三类摄谱与调试对中各自为战，充斥 `#70e3e8` / `#00ffff` 荧光青底配 `#be2424` / `#c41616` 刺眼红字、高饱和 `#a8c9eb`/`#a6caf0` 底板。
- **改造后**：
  - 在 `styles/global.css` 的 `:root .app-shell` 与 `:root[data-theme='dark'] .app-shell` 集中定义统一品牌主蓝（`--action-blue: #205fc8`）与完整明暗双主题 `--spec-*` 科学绘图令牌：
    - 浅色：`--spec-board: #dfe9f5`、`--spec-banner: #edf4fc`、`--spec-label: #294761`、`--spec-primary-curve: #c32d35`、`--spec-reference: #245f93`、`--spec-located: #237453`、`--spec-crosshair: #236cdf`；
    - 深色：`--spec-board: #253c54`、`--spec-plot: #172638`、`--spec-banner: #1d3046`、`--spec-label: #d6e5f4`、`--spec-primary-curve: #ff8685`、`--spec-reference: #83beff`、`--spec-located: #76d6ad`。
  - 全面覆盖 8 大核心图面（样品分析、谱图查看、色散曲线、蒸发曲线、样品/色散/蒸发摄谱、调试对中）；`SpectrumPlot.tsx` 撤除优先级红线 `!important` 覆盖，曲线宽度统一 `1.25px`。
  - 调试对中（`alignment-monitor.css` & `AlignmentMonitor.tsx`）替换 `#00ffff` 刺眼峰值条为明暗双态提示条，并给活动通道（`.alignment-row.active`）整组左轴标值、左指示条与绘图框四周加上高对比主题活动高亮，远距依然一目了然。

### 3.2 表格选中态与状态语义统一
- **改造前**：多点位表格选中行硬编码高饱和 `#0679c1` 亮蓝条，在深浅色谱图中非常突兀；样品分析左栏覆写为普通白底、摄谱左栏按钮字体脱离行色；任务列表状态为普通纯文本且删除按钮常驻刺眼红框。
- **改造后**：
  - 引入 `--spec-row-selected-bg / --spec-row-selected-fg / --spec-row-selected-mark`（浅色 `#e1edf7 / #203e57 / #417ba5`，深色 `#304a63 / #e5f1ff / #91bde5`），统一查看表、多点位表（首列 `3px` 左指示条）、分析左栏与摄谱记录表的行选中效果。
  - 摄谱任务列表（`SpectroscopyTaskList.tsx`）新增柔和语义胶囊（草稿／待开始、运行中、暂停／停止中、已停止、已失败、已完成；精确处理 `HardwareAcquisitionPage` 第 4 个调用方避免将失败终态误显为绿色）；操作列「进入摄谱 / 查看谱图」主次清晰，删除垃圾桶默认柔和灰，仅悬停/聚焦呈现危险红。

### 3.3 主框架壳层瘦身、导航与去重
- **改造前**：侧边栏宽 `246px` 且一级导航无图标，选中态带厚重投影；「当前方法」在顶栏和侧栏左下重复出现两次；顶栏 `52/48px`、快捷栏高且全白、底部折叠消息栏 `45px` 偏厚。
- **改造后**：
  - `Sidebar.tsx` 收紧至 `216px`，为一级导航补齐统一的 `lucide-react` 线框图标，去除过重蓝阴影，删除侧栏左下重复的 `.sidebar-method-state` 卡片（将「已暂停」状态合并进顶栏右侧唯一 `.workspace-method` 胶囊）。
  - `quick-access.css` 与 `message-panel.css` 统一顶栏高 `46px`、快捷栏高 `36px`（配 `--workspace-shortcut-bg` 柔和浅底区分层级）、折叠态底部消息栏总高 `34px`，并定义 `--workspace-available-height` 统一联动各工作台视口高度计算（`1440×900` 下可用高度从旧版扩展至 `784px`、`1060×680` 下为 `564px`）。

### 3.4 图标体系分层统一（严格守住保留边界）
- **改造前**：通用页头方框、摄谱激发 5 键、摄谱右栏工具、队列/自动转角通用表单按钮中混用了彩色重绘 PNG（如红底白加号圆球、黄扫帚、紫小门），导致与现代线框按钮视觉打架。
- **改造后**：
  - **已统一为 `lucide-react` 单色线框图标（`strokeWidth={1.75}`）**：通用页头左图标框（`36×36px` 柔蓝底 + `22px` 线框图标）、摄谱激发 5 键（`Play`、`StepForward`、`Flame`、`Square`、`LogOut`）、摄谱右栏 3 键（`ClipboardPenLine`、`ListPlus`、`Eraser`，独立封装 `SampleInputToolButton.tsx`）、队列清空/插入按钮与自动转角通用表单动作按钮。
  - **严格保留的专业/功能图标**：样品分析 27 枚重绘专业图标（`SpectroscopyIcon`）、顶部快捷栏 8 枚快捷图标（`QuickAccessBar`）、侧栏二级飞出菜单功能图标（`FunctionIcon`）及摄谱中央观察工具栏专业图标均完整保留且通过回归核对。

### 3.5 摄谱工作台对齐与 `1060×680` 窄窗可读性
- **三栏底边 0px 齐平与激发区层级**：常规/高屏下，`.spectroscopy-command-area` 保持 `flex: 1` 完整撑满到底边（与左栏谱带表、中栏绘图框底边实测相差 `0px`），4/5 个控制按钮在框内纵向均匀排布；`试样摄谱` 提升为主蓝实心焦点，`停止摄谱` 在可用时以危险红底红字突出警示。
- **窄窗（`1060×680`）五按钮无滚动条**：`@media (max-height: 760px)` 下紧凑排版使双转角 5 按钮全部完整可见，激发区 `fieldset` 无多余垂直滚动条（`scrollHeight <= clientHeight + 1`）；中央观察工具栏通过 `container-type: inline-size` 在窄屏下自动双行换行且不溢出。
- **列表与栏宽修复**：
  - 谱图查看样品记录表左栏调为窄窗 `188px` / 常规 `216px`、摄谱样品记录表调为窄窗 `204px` / 常规 `232px`，`1060×680` 下表头「记录号 / 样品编号 / 样品序号」不再截断成 `样...` 也不再紧贴粘连。
  - 「定位谱线」与「曝光区间」输入框按实测统一为 `120px`，完整容纳高精度波长与区间范围。
  - 谱图查看展开的「估算浓度」面板长提示改占整行左对齐，消除窄栏单字换行（如“浓/度”）；蒸发曲线「分时数据」面板改用 `subgrid` + 不换行规则，第 10–18 次积分强度单行完整对齐不折字。

- **旧数据迁移（`migration.css`）**：整张来源卡片与历史卡片统一 `max-inline-size: 1080px`，内部提示条、目录选择区、三条路径输入框与提交按钮左右边缘完全齐整，兼顾宽屏舒适度与对齐感。
- **打印与导出（`ReportBuilder.tsx`、`ReportOutput.tsx`、`remaining-pages.css`）**：两处业务空态改为虚线浅灰边框 + 淡色居中图标 + 主副引导文案的精致轻量卡（约 `57.4px`），底部打印机选择与导出按钮网格齐整。
