## 5. 已确认缺陷

### F-01（P1，发布阻断）：声明允许的 FastAPI 环境中后端无法正常导入

- 复现：在 `app/` 执行 `python -c "import backend.app.main"`，或执行标准 `python -m pytest -q -p no:cacheprovider`。
- 实际：FastAPI 在注册 `POST /api/v1/auth/logout` 时抛出 `AssertionError: Status code 204 must not have a response body`；测试在收集阶段中止。
- 期望：README/package script 所声明的普通 Python 启动与完整 pytest 门禁可运行。
- 证据：`app/backend/app/main.py:628-632` 使用 `status_code=204` 且处理函数返回注解为 `None`；`app/backend/requirements.txt` 允许当前 FastAPI 0.115.0。
- 影响：开发后端无法按文档启动，全量测试不可重复；当前冻结 sidecar 可以运行并不能消除源码/重建风险。

### F-02（P1，数据正确性）：谱线无效数值可静默提交旧值

- 复现：在“分析谱线”新建谱线，把理论波长从 254 改成超范围的 9999，保持界面显示 9999 后点击“添加谱线”。
- 实际：界面没有阻止提交，生成方法草稿 v4；数据库中新增谱线仍是旧的 254 nm。
- 期望：拒绝保存并聚焦/提示 160–800 nm 范围错误，不得用不可见的旧状态代替用户输入。
- 根因证据：`NumericInput.tsx:67-75` 在无效文本时不更新上层值；`App.tsx:972-979` 的谱线保存没有调用 `reportInvalidNumericInput`，`App.tsx:1075` 的按钮直接提交 `draft`。
- 影响：用户看到的值与实际保存值不一致，属于静默数据错误。

### F-03（P1，核心功能）：建立定量分析运行无反馈、无记录

- 复现：进入“定量分析与慢进”，选择一个或两个已完成且固化的 QA001 输入，分别用鼠标、Tab+Space、Tab+Enter 激活“建立并锁定输入”。零选择时也复验一次。
- 实际：无成功/失败提示，页面无新运行；关闭后数据库 `analysis_runs=0`。
- 期望：合法输入建立运行；当前发布方法 v3 没有启用分析线时，至少应显示后端 `analysis_lines_missing / 方法版本没有已启用的分析线`。
- 证据：`AnalysisPage.tsx:70-80` 声明了成功/失败 toast，`AnalysisPage.tsx:164-168` 使用 form 提交；后端 `analysis.py:379-386` 明确检查分析线并提供稳定错误码。实际交互没有进入可见结果。
- 影响：桌面端定量分析主流程无法开始，继而阻断质控、曲线和正式报告的桌面闭环。根因仍需进一步定位。

### F-04（P2）：工作台“方法管理”快捷入口路由到错误子页

- 复现：从工作台点击“方法管理”或顶部当前方法。
- 实际：有当前方法时进入“方法参数”；无当前方法时会被“请先选择已发布的当前方法”拦住，无法通过快捷入口进入方法库。
- 期望：进入“方法库与当前方法”。
- 根因证据：`App.tsx:494`、`App.tsx:536` 只传入通用 page `methods`；`navigation.ts:88` 先按 order/key 排序，`navigation.ts:118-120` 再取第一个相同 page。`conditions.parameters` 和 `methods.lifecycle` 都是 order 10，前者按 key 排在前面。

### F-05（P2）：维护默认备份目录相对于进程工作目录解析

- 复现：保持“备份目录”为默认 `backups`，点击创建在线备份。
- 实际：在项目根目录创建 `C:\Users\Leo\Desktop\地质局\backups\...sqlite3`，而不是隔离数据目录或 Windows 用户数据目录。
- 期望：默认使用设置中的绝对备份目录，或基于应用用户数据目录解析；不能依赖启动工作目录。
- 根因证据：`MaintenancePage.tsx:19` 把本地状态硬编码为 `backups`；`maintenance.py:152-165` 直接用 `Path(output_directory)` 创建相对目录。
- 影响：从项目目录启动会污染项目根；安装到受保护目录时可能失败或写入不可预期位置。
- 收尾：本轮生成的唯一备份已原样移到 `app/.local/full-test-20260905-003551/root-output-evidence/backups/`，SHA-256 `210A9FD7EFEF2AE8214F131B8349AAA6DF6EAB871042C7C319E7BFB045FF6E6A`，项目根 `backups/` 已不再存在。没有修改历史资料。

### F-06（P3）：工作台服务状态为硬编码占位文案

- 实际：在已运行的打包桌面程序中仍显示“事件流 `/ws/events` 待连接”和“桌面壳 Tauri 2 构建中”。
- 证据：`App.tsx:536` 固定输出两个 `protocol-pending` 状态。
- 影响：不影响业务数据，但会误导现场人员判断服务是否就绪。
