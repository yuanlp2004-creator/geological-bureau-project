## 当前工程基线

- **应用形态**：FastAPI + React 19 / TypeScript + SQLite + Tauri 2 Windows 桌面应用（[GeoSpectrum.exe](../GeoSpectrum.exe)）
- **代码基线**：18 个后端注册模块、七组侧边栏导航、SQLite **schema v32**；前端单测 **119 项通过**（含 Canvas 2D 混合谱图引擎、浅/深双主题、Icon Rail 折叠与专注模式、三层硬件锁仲裁、标准曲线质控与谱线库 CCD 覆盖带）
- **历史证据与外部门禁**：分步验收报告与 S00 黄金样本路径保持原样不变；真实转角/汞灯硬件及代码签名外部门禁状态见 [当前验收状态](acceptance-reports/README.md)。
