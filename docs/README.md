# GeoSpectrum 文档索引

`docs/` 用于保存项目计划、研究说明、验收证据、发布资料和用户文档。`PLAN.md` 保留在项目根目录；阅读指南和两个 S00 工具依赖的参考文件保留在 `docs/` 根目录。

使用软件请打开 [GeoSpectrum 离线使用手册](使用与说明/GeoSpectrum_使用手册.html)：分层目录、全文搜索和主题跳转，双击文件即可阅读。

## 归档规则

- 新的专项实施、修复或学习计划进入 `规划与计划/`；`从头搭建学习计划.md` 按用户要求移至相邻 `GeoSpectrum-rebuild/` 根目录维护，本索引保留链接入口。
- 新的用户操作说明进入 `使用与说明/`，同一资料的 PDF 与 Markdown 放在一起。
- 协议、截图、演示文档和外部参考材料进入 `参考资料/`。
- 验收证据只进入对应 `acceptance-reports/Sxx/`，不复制到其他目录。
- 可再生的临时文件、日志、数据库和测试输出进入 `app/.local/` 或系统临时目录，不进入 `docs/`。
- 不移动或重命名 `PLAN.md`、`ui-test-homepage-reference.png` 和 `项目重构Plan提示词与UI参考_AI执行版.md`，除非同步修改 S00、发布工具和治理文档中的固定路径。

按用户要求，可直接运行的 [`GeoSpectrum.exe`](../GeoSpectrum.exe) 与配套 `geospectrum-backend.exe` 保留在项目主目录。安装包位于 [`app/.local/releases/0.1.0/`](../app/.local/releases/0.1.0/)，该目录不进入版本控制。归位及后续调整记录见 [2026-09-05 项目清理记录](测试报告/2026-09-05-项目清理记录.md)。
