# 浏览器验证说明

使用项目允许的本地浏览器客户端 `browser/26.730.61639`，通过本地 FastAPI（8787）和 Vite（5173）服务完成端到端冒烟验证。未使用 `UI测试/` 截图替代产品验证。

## 已验证交互

- 工作台加载后显示“已连接”、SQLite WAL、外键已启用、注册模块和运行消息。
- 点击“方法”等未启用业务域显示“方法将在后续步骤启用”，页面不跳转到伪实现。
- 软件设置选择“紧凑”并保存，刷新页面后仍为“紧凑”；点击“恢复默认”后回到“舒适”。
- 运行消息按“信息”筛选后只显示信息事件，单条消息可被选中；复制按钮可用但系统剪贴板回读为空，因此不将剪贴板内容回读作为通过依据。
- 关于与诊断页显示 SQLite `ok`、日志模式 `wal`、外键约束“已启用”、事件数量和模块清单。
