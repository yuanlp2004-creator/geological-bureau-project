# 双 COM 摄谱联动核对

## 端口与协议

- CCD 采集档案指定一个通讯口。正式采集沿用旧版已确认的 CCD 帧、激发及结束流程。
- 转角电机选择另一蓝牙传出 COM 口。Windows SPP 提供串口，独立电机服务通过该串口执行已实现的 AgeMotion RTU 定位和停止。服务通过本机回环 HTTP 与 GeoSpectrum 联动。
- 本机软件枚举读到 COM3 为蓝牙传出，COM4 为蓝牙传入。当前端口枚举未发现 CCD 有线口。设备历史记录把 COM3 映射给 DM02，设备型号及其与交付仪器的关联须现场核对。
- 本项目提供 `StandaloneMotorApi/rtumotor_api/` 和 `docs/motor_api_completion.md`。旧版串口组件位于 `Spec Source/Bin/PCOMM.DLL` 和 `Spec Source/Res/PCOMM.DLL`。独立 API 使用 pyserial，蓝牙由 Windows 配对及 COM 映射处理。本轮无另供的厂商专用蓝牙库。

## 现场接入

1. 在「设备调试 → 设备参数」选择实际 CCD COM 口；在 Windows 完成电机蓝牙配对，核对它的传出 COM 与 CCD 口不同。
2. 准备与现场记录一致的电机服务档案，明确驱动器、通信参数、传动比、方向、零点、范围、补偿量和到位条件。独立服务的档案模板用于核对字段。
3. 从项目目录启动本地电机服务。以下名称中的配置文件路径和 API 端口以现场配置为准。默认桌面数据目录的凭据文件用于 GeoSpectrum 到本机服务的鉴权。

   ```powershell
   python StandaloneMotorApi/run_server.py --profile 'C:\仪器配置\motor-verified.json' --port 8790 --token-file "$env:LOCALAPPDATA\cn.geospectrum.desktop\motor-api.key"
   ```

4. 在「设备调试 → 设备连接 → 转角电机」绑定蓝牙传出 COM、本机服务端口及相同的现场标定编号，逐项录入已确认的方法转角与电机坐标。电机服务须报告真实串口、有效参考和已验证运动配置，所有目标须在该档案的有效范围内。
5. 色散、蒸发和样品的「试样摄谱」连续执行多转角计划。色散、蒸发的「仅摄本转角」仅运行当前角的独立任务。样品按整次重复采齐并入库，单角操作后由操作者开始下一角，下一重复仍需装样后启动。

## 汞灯比对和现场验收

- 「设备调试 → 汞灯谱线比对」读取实际参考与观测 CSV 的「点位、强度」。填写参考来源和已知角，点选同一 CCD 的对应峰，查看观测减参考的点位差。依据现场标定确认目标方法角后，可以保存 JSON 定位记录，也可以把该记录带入指定 CCD 档案的电机绑定。经确认的电机坐标和标定编号由操作者填写。
- 现场须补 CCD 响应与激发收尾、电机型号及蓝牙链路、各角实际到位及重复性、停止与断线后状态、光学稳定和汞灯参考谱来源。当前软件证据采用模拟器、回环电机接口夹具和伪 CCD 字节流，S14 和 S15 的真实硬件验收状态仍为 `deferred_external`。
