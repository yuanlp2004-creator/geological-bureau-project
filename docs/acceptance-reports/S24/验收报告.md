## 核心验收与命令结果

命令从 `app/` 执行。UI 脚本要求 `QA_ISOLATED=1`、`QA_OUTPUT` 和 `PLAYWRIGHT_MODULE`；浏览器另设 `QA_URL`，桌面设 `QA_CDP`，迁移设 `QA_SOURCE_DIR`。新种子 `python tests/seed_s24_ui.py <新空数据目录>` 使用指定的新空数据目录；测试账号与所有业务写入仅在隔离目录内。

|---|---|
| `npm.cmd run frontend:build` | TypeScript + Vite 通过；保留既有大于 500 kB 的分块提示 |
| `npm.cmd --prefix frontend test` | 现有数值输入 4 项通过 |

主流程：选择方法 → 建立队列（重复 2 次）→ 新建采集 → 收起/展开 → 暂停/继续 → 完成；非法数值零写入、服务拒绝后输入保留均通过。独立 S16 黄金输入实际执行分析；独立 S17 黄金批次执行统计、拟合、发布、合并，再生成、预览、确认并输出报告，输出文件头为 `%PDF-`。这些是分段业务回归，不据此宣称新采集模拟输入的定量数值真值已获得硬件验证。

转角模拟任务验证开始与安全停止；汞灯模拟会话验证应用与回退；色散验证暂停/停止及谱线不足禁止拟合。调试曲线指针误差小于 3 CSS 像素；标准曲线首末点与 SVG 边界误差小于 1 像素。隔离数据库备份及校验通过。

迁移使用原件副本：有效运行目录方法库/配置、CDT、DAT 实际预览和提交，重复提交保持幂等；CMT 实际导入并执行 1–2 区间，越界区间拒绝。9 个历史原件的字节数、修改时间与 SHA-256 复核一致。`Spec Source/Bin/DIRECT.MTD` 中波长低于既有校验下限的内容仍被拒绝，没有放宽解析约束；正常迁移改用 `Spec2.02` 有效运行副本。

只读角色看不到创建入口，后端创建返回 403，维护写入禁用。设置接口拒绝后路径输入保留；不存在来源与无效备份目录清楚报错。登录失败使用实际认证接口；离线页与首次初始化模式用路由模拟状态验证，密码确认不一致时初始化写入为零。
