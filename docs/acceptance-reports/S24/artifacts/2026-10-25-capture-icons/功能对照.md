# 旧版与新版摄谱工作台功能对应

2026-10-25，仅比较摄谱实时视图与其相关工具，不据图标数量判断完整业务等价。

依据：`Spec Source/Source/Main/mmAnalyze/FmView.dfm/.pas`、`FmDockGuideIgnit.dfm/.pas`、`Spec Source/Source/Common/DmResource.dfm`；新版当前源码 `SpectrumInspector`、`SpectroscopyConsole`、`SpectrumViewToolbar`、`SpectrumViewerPage`、`DispersionLines`。用户截图中很多图标呈灰色，因为当前无谱带/没有相应数据，不能把可见图标都算成当前可用功能。

| 旧版入口/作用 | 新版当前位置/差异 | 本次处理 |
|---|---|---|
| 十字线、滚动、区域放大 | 三类摄谱实时谱图原来共用一个工具下拉框 | 改为三个直接可见的图标按钮，原动作保持 |
| 横向与纵向放大/缩小、适合图像 | 实时谱图已有，原来是文字按钮 | 换为旧图标高清重绘版，悬停看名称 |
| 试样摄谱、预热摄谱、停止摄谱 | 摄谱控制区已有，手动逐次重复 | 换为旧版高清图标，保留可见文字和原权限/流程 |
| 上下谱带、上下CCD | 历史数据在“谱图查看”有记录/CCD/谱线切换；实时摄谱使用CCD选择器 | 入口形式不同，没有本次增加上一/下一快捷键 |
| 一线一点、一线四点、十倍CCD | “谱图查看”有100%、400%、十倍CCD；实时采集区没有这三个预设 | 是当前工作台入口缺口，不能称整个新版都没有 |
| 纵向单独还原 | 实时谱图仅有“适合图像”同时还原双轴；“谱图查看”有还原视图与参考校正 | 实时区缺少独立的纵向还原 |
| 多样品叠加、优先曲线 | “谱图查看”支持1–8条原始样品叠加和优先曲线 | 已有能力，未集中在实时摄谱区 |
| 参考线校正、谱线定位 | “谱图查看”与“色散曲线”分别承载；后者有全部定位、逐线短波/长波移动、保存/恢复实测位置 | 不把这些需要方法/数据上下文的动作复制进采集控制区 |
| 谱线锁定 | 旧版针对分析谱线；新版实时观察锁的是点位；谱图查看另有谱带记录锁定 | 两者不同，不能宣称完整等价；图标悬停明确“锁定点位/解除锁定” |
| 打印CCD图像与细节 | “谱图查看”提供打印PDF和CCD打印范围/图层/比例/纸型 | 已有入口，实时工作台不直接提供 |
| 结束 | 新版采集完成后保存/下一样品，以及返回任务列表，运行时受保护 | 不能按外观把旧“结束”按钮当成新版“停止” |

因此，功能显得较少来自三个原因：旧版把查看、定位、采集集中在一个共享窗口；新版将这些工作分到实时采集、色散曲线、谱图查看；实时采集区确实缺少若干快捷视图。此外，点位锁定与旧谱线锁定不是同一语义。

本次只完成获准的图标替换和入口显现。未补齐上述缺口，也未改变API、算法、数据库或设备协议。真实设备采集能力仍按既有硬件证据确认。
