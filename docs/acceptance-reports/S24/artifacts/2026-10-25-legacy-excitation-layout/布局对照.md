# 摄谱激发工作台布局对照

本批按用户旧版截图、`FmView.dfm`、`FmDockAwareSam.dfm`、`FmDockGuideIgnit.dfm`重排当前摄谱面板；不替换应用外壳和已确认的任务准备流程。

| 旧版区域 | 当前实现与数据来源 |
| --- | --- |
| 顶部选择谱线、定位谱线、曝光区间 | 恢复横向排列。样品谱线来自当前任务绑定的确切已发布方法版本；波长和曝光区间只读。色散使用本任务谱线，选择后同步CCD及当前定位谱线。无方法或无权限时禁用。 |
| 左侧全时／均值样品、工具、小表格 | 按实际保存类型显示标题，表格为记录号、样品编号、样品序号；保留记录锁定和实时／已保存谱带切换。 |
| 中部一排工具和大谱图 | 谱带前后、CCD前后／选择、十字线、滚动、区域、比例及双轴工具集中一行；无谱图采用旧版浅蓝背景。 |
| 右侧摄谱窗口、样号输入 | 样号下拉与重复摄谱常驻。选择同队列待测项时，使用当前任务的设备、方法版本、CCD与激发条件建立对应草稿；重复次数从队列带出，不启动设备。再次选择已有项复用其任务。 |
| 右侧激发控制 | 试样摄谱、预热摄谱、停止摄谱、结束四项纵向等距；暂停／继续位于上方小工具区。 |
| 紧凑图标 | 40枚原高清资源保留，显示16 CSS像素；常规工具按钮24像素，窄窗口谱图工具以20像素为基准，必要时缩至18像素，图标仍为16像素。 |
| 任务条件、采后命名、进度 | 条件和命名折叠于右侧底部，进度集中到底部状态条，原有操作仍可用。 |

## 保留的操作差异

- 初次建立任务仍使用独立准备窗口；当前工作台只切换同方法／同队列的已有样品及待测项，不把历史库全部混入下拉。临时新样号仍通过输入样品编号工具建立。
- 顶部定位谱线显示该线波长，曝光区间显示任务方法版本的区间；没有复刻旧版在此手输任意波长或临时改区间重算的动作。当前任务与方法历史不会被这些观察控件改写。
- 左表限定当前任务的已保存重复／帧，全库历史与多样叠加仍在谱图查看。左工具为显示最新／返回实时及记录锁定，不清除正式样品数据。
- 运行、暂停和控制请求期间禁止切换样号；预热独立，下一次重复仍需人工激发。读取失败保留原选择，不用实时曲线冒充历史谱带。
- 应用外壳、明暗主题、权限、历史快照、色散拟合和打印边界保留。本批是摄谱区域布局对齐，不宣称整个旧软件逐像素或全部业务动作等价。

## 验证

浏览器17组／8布局、实际QA桌面15组／8布局；原摄谱回归浏览器及桌面各5组／8布局，前端15项、后端16项通过。主流程覆盖样号切换、带出重复数、保持当前条件、一次点击一次重复、激发期间锁定、只读权限、谱带观察、真实比例、PDF、色散定位与拟合。浏览器另验证切换失败保留原值并重试。

正式／QA源码及前端资源一致；两次实际QA正常退出，无所属残留。后端源码及EXE保持，旧源只读，使用隔离库测试。根目录配对程序更新后，关闭旧窗口再重新打开生效；安装包未更新。
