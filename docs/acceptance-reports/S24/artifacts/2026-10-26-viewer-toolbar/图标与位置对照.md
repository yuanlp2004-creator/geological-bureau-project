# 查看工具图标与位置对应

依据用户新旧工具区截图及只读旧源 `FmView.dfm`、`FmView.pas`、`FmViewMulti.pas`、`FmDockAwareSam.dfm/.pas`。

| 工具区 | 本次对应 |
|---|---|
| 样品顶部 | 样号录入、参考校正、谱线定位、开始、暂停、分隔、关闭 |
| 左侧样品表上方 | 样号录入、清除样号、多样品查看、记录锁；标题关闭可恢复 |
| 图像工具 | 上下谱带、左右CCD、九宫格CCD下拉、分隔、十字线/框选/滚动、分隔、适合/1:1/1:4/10/横向加减、分隔、纵向加减/还原、分隔、打印 |
| CMT多样品 | 依据旧FmViewMulti隐藏滚动；多样品与记录锁从顶栏/额外状态行回到左侧 |
| 色散顶部 | 增/删、选线/定位/曝光、谱线定位/拟合、分隔、关闭；处理设置移至文件行 |

所有查看图标复用现有Qwen高清资源，未重绘；按钮23×24 CSS像素、图标16像素，常态透明无框无圆角无阴影。十字线/框选/滚动选中、悬停与键盘聚焦保留提示。九宫格下拉仍使用原生select，鼠标与键盘均可切CCD。

原始帧、分时明细、蒸发帧统计放文件操作行，不冒用旧工具图标；色散输入点位移至图框底部。关闭按钮通过现有导航离开查看页，不停止应用进程。

查看页没有测量任务，开始/暂停禁用；旧源ClearSamps会写入样品编号，编号录入/清除在此只读页禁用并提供原因，未增设假动作或回写旧文件。原记录锁、Ctrl叠加、曝光、参考偏移、定位、原始帧、分时与统计窗口、PDF及权限保持。

浏览器与实际QA各22组/22布局、前端16项通过。四种尺寸/密度/主题下逐项核对图标顺序、尺寸、常态透明及CCD键盘操作；含真实WDT/CMT/EDT、503清图/重试、只读权限、三个关闭入口、列表关闭/恢复及原始数据校验。色散摄谱外框边界最大误差见verification.json。旧源、后端、Qwen资源及用户数据不改。安装包未重建。
