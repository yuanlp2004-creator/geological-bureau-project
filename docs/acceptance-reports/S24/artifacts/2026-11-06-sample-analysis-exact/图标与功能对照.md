# 样品分析图标与功能核对

图标直接取自旧版 `IlGlobal`／`IlSamp`，保留原始16×16像素及透明蒙版。27个常驻位置、28份资源（含解锁态）。只作用于样品分析页，其他页面的高清资源保持。

| 相对位置 | 图标 | 旧动作／资源索引 | 新版对应动作 |
|---|---|---|---|
| 顶栏 | 录入样品编号 | ActSampInput / 28 | 打开编号表，保存当前分析副本 |
| 顶栏 | 校参考线 | ActLocateRef / 17 | 计算参考线实测位置并定位；不自动改写方法 |
| 顶栏 | 校正谱线 | ActLocateLines / 18 | 计算当前样品各谱线实测位置并定位 |
| 顶栏 | 开始／继续测量 | ActStart / ActRun / 19 | 沿用当前运行开始或继续；编号为空禁止开始 |
| 顶栏 | 暂停测量 | ActPause / 20 | 当前请求完成后停止继续推进 |
| 顶栏 | 关闭 | ActClose / ActStop / 22 | 关闭当前分析数据；运行中先停止 |
| 左侧 | 录入编号／清除编号 | IlSamp 0 / 1 | 录入编号或清空编号；原运行和采集输入保持 |
| 左侧 | 锁定／解锁记录 | IlSamp 2 / 3 | 只锁定样品记录切换；CCD和谱线选择不受影响 |
| 图像工具栏 | 上一／下一谱带 | ActUp / ActDown / 1 / 0 | 切换当前分析内的相邻样品记录 |
| 图像工具栏 | 上一／下一CCD／CCD选择 | ActLeft / ActRight / TbSelCcd / 3 / 2 / 26 | 切换实际存在的CCD |
| 图像工具栏 | 查看／区域放大 | ActCross / ActSelectZoom / 4 / 6 | 读数、锁点或框选放大 |
| 图像工具栏 | 滚动 | ActScroll / 5 | 拖动灰度谱带进行横向滚动；曲线区不进行自由平移 |
| 图像工具栏 | 适合图像 | ActFit / 7 | 横向显示完整谱带，不重置纵向范围 |
| 图像工具栏 | 1:1／1:4／10倍CCD | Act100 / Act400 / ActCCD10 / 8 / 9 / 10 | 像素比例或依据真实屏幕及CCD点宽的物理比例 |
| 图像工具栏 | 横向放大／缩小 | ActZoomIn / ActZoomOut / 11 / 12 | 只改变横向可见跨度 |
| 图像工具栏 | 纵向放大／缩小／还原 | ActZoomYIn / ActZoomYOut / ActZoomYReset / 24 / 25 / 27 | 改变或还原纵向范围；还原恢复原始环形箭头图标 |
| 图像工具栏 | 打印 | ActPrint / 14 | 当前样品、CCD和曝光区间的同源灰度及曲线PDF |

旧Access原件保持只读；编号操作通过分析副本实现，已经生成的分析结果不改写。编号录入不再打开通用分析设置，清除也不再是永久禁用的空按钮。原有建立运行、结果复核、重新读取与列表恢复保留在谱图右键操作菜单，不增加顶部常驻按钮。本批按用户更正暂不调整间距。
