# 谱线与谱图工具按钮旧版核对（2026-10-31）

核对对象为用户截图中的色散谱线工具栏，以及它使用的共用谱图工具。以 `Spec Source/Source/Main/mmAnalyze/FmView.pas/.dfm`、`FmViewSingle.pas` 和 `FmWstc.pas` 为依据；本次未修改旧版原件。

| 按钮／控件 | 旧版依据与行为 | 本批结论 |
|---|---|---|
| 增加谱线＋ | FmViewSingle.ActAddLineExecute，182–207行：当前CCD点位增加TWdtLine，拒绝重复点位，随后选中；波长稍后填写 | 修正为直接增加实际点位，未填波长明确显示待填写；不再展开添加表单 |
| 删除谱线－ | ActDelLineExecute，210–223行：删除当前谱线，清空选择 | 修正并验证真实删除；未选线时禁用 |
| 选择谱线／图中谱线标记 | FmView.SelectLine、CbLinesSelect：选择并切换所属CCD、定位图中位置 | 增加图中标记选择；列表、CCD及点位联动 |
| 定位谱线输入 | FmView.EdtWaveKeyPress，1016–1055行：输入波长或CCD,点位，回车定位 | 取消只读；支持两种输入与范围拒绝；CCD和点位均按1起输入 |
| 曝光区间 | FmView.EdtExpSegKeyPress：区间决定显示计算 | 保留已有区间API；旧WDT仍用旧版积分强度，新采集显示区间均值且标明来源 |
| 校正谱线 | FmView.ActLocateLinesExecute：执行全部谱线寻峰校正 | 真实读取已保存燃烧/暗帧，在当前点位附近寻峰；修正此前固定从预期波长点开始的问题；不重复叠加历史移动量 |
| 拟合曲线 | FmViewSingle.MinWstcLineCount=4、ActFitWstcExecute；FmWstc.AclWstcUpdate要求所有波长>0 | 四条线起开放拟合窗口；未填已知波长不能拟合；API旧版拟合也要求四条，既有通用三点数学API保留 |
| 拟合窗口波长保存 | FmWstc.CheckWave：逐行填写已知波长 | 空值明确未填写；逐行校验，不被其他待填行阻挡；不改变实测点位 |
| CCD间隔／增量／重算 | FmWstc.CbGapsSelect、CbIncSelect；增量1/5/10μm | 保留任务专属布局与重算；增量改为1/5/10；方向键按增量调整，浮点原始间隔不因整数步进误报 |
| 移向短波／长波 | FmView.ActMoveLineExecute：当前线移动一个点 | 在工具栏接通实际移动，保存还原点保持 |
| 保存／还原实际位置 | FmView的波长位置保存/加载链；新版保留任务位置快照与不可变曲线 | 接入当前线的保存和还原；修改定位后原拟合草稿不可发布，需重新拟合 |
| 上一／下一谱带 | FmView.ActUp/DownExecute | 保留真实记录切换及边界禁用 |
| 上一／下一CCD、CCD选择器 | FmView.ActLeft/RightExecute、miSelCcdClick | 保留真实CCD切换及边界禁用，跨CCD定位不再丢失加线点位 |
| 查看（十字线）／区域放大／滚动 | FmView.ActCross/SelectZoom，FmViewSingle.ActScrollExecute | 保留观察工具；框选结束回到查看工具，峰形/灰度共用坐标 |
| 适合图像 | FmView.ActFitExecute，344–348行：FitToWidth、ZoomX | 修正为仅还原横向；保留纵向缩放与选点，普通谱图查看页同步 |
| 一线一点／一线四点／十倍CCD | FmView.Act100/400/CCD10Execute | 保留100%/400%像素比例与设备点宽、屏幕参数换算；无有效物理参数时禁用十倍CCD |
| 横向放大／缩小 | FmView.ActZoomIn/OutExecute | 保留横向倍增/减半与视野联动 |
| 纵向放大／缩小／还原 | FmView.ActZoomYIn/Out/ResetExecute | 以显示下限为锚缩放；纵向还原不改变横向视野 |
| 打印谱图 | FmViewSingle.ActPrintExecute | 旧WDT仍通过已有可见范围PDF链输出，浏览器下载与桌面PDF字节均验证；未打开原生打印机窗口 |
| 打开文件／刷新／隐藏恢复列表／处理设置／关闭 | 旧版文件/停靠面板及窗口操作；新版已有页面导航 | 保留现有对应入口；处理设置与拟合共用按需窗口，关闭保留已保存数据 |

## 验证与兼容边界

- 浏览器和打包QA桌面均通过10组操作检查、浅色1440×1000和深色1060×720布局；包含实际鼠标选点、输入定位、增删、重复拒绝、四点拟合、逐点移动/保存/还原、实际帧寻峰、缩放与真实PDF。
- 前端20项、后端14项及TypeScript/Vite构建通过。新API继承色散读写权限，验证未登录拒绝、非整数点位、CCD范围和重复点位；没有修改数据库schema。
- 旧软件只在WDT显示增删按钮，普通样品谱图继续按该规则处理；本批没有把色散点位增删错误地接到方法分析谱线。
- 新采集且没有旧文件来源的谱图，目前仍缺少这条色散PDF输出路径，打印按钮明确禁用；旧文件打印和PDF输出已验证。此项是既有差异，不能据本次验证宣称全软件所有按钮与旧版完全等价。
- 新版保留已发布曲线/方法不可变、权限、审计和用户数据保护；旧软件直接回写Access的方法不照搬。真实转角/汞灯协议、仪器和实体打印仍由既有验收门禁处理。
