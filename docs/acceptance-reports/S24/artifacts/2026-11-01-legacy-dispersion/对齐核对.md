# 色散曲线按旧版对齐核对

| 旧版依据 | 新版结果 |
|---|---|
| FmWstc.dfm：顶部工具／左373右262 | 摄谱、曲线两个入口共用独立窗口，顶部CCD区间／间隔／标尺／拟合／保存／退出，左表右结果；删除底部浮动面板和重复组件 |
| FmWstc.DisplayModal／DisplayStep | 序号、谱线波长、谱线位置、测量步数、校正步数、步数误差六列；仅波长可编辑；点位从1起，统一步数从0起含前CCD长度与间隔；误差=测量−本次拟合 |
| FmWstc.CalWstc／DisplayWsCof | 截距C、一次B、二次A、每步波长、波长范围、步数范围；每步波长按相对首条线的比值求平均；步数范围取首／末实测与拟合端点 |
| uGlobal.FormatStep／FormatWave | 步数／误差一位小数、波长四位、C一位／B五位／A七位／每步波长五位；保存使用未舍入误差门禁 |
| FmWstc.CheckWave、uGlobal允许范围 | 160–800nm，回车或离开提交，非法值还原；兼容API通过可选legacy_input启用 |
| FmWstc.CbGapsSelect／SpeGapChange | 初始区间未选择，选中后整数显示，标尺1／5／10μm；标称9809±允许误差（原OPT的CcdGap可迁入）；只重算测量步数并使旧结果失效，不自动拟合 |
| FmViewSingle.ActAddLineExecute | 主谱图选点＋增加、−删除，网格填写已知波长；没有新增元素／波长／CCD表单或逐行按钮 |
| TWdtLine.Create(...,10)／uAnaThread.SetRange | UI校正使用旧版10点窗口，固定基准；无峰／歧义拒绝并保持位置；兼容API仍可沿用既有窗口 |
| FmView.ActMoveLine／PmAnaBtnSet | Ctrl左右微移；谱线标记／列表右键有前后线、优先显示、删除、恢复当前或全部位置、保存全部位置；批量保存恢复短事务与审计 |
| FmWstc.ActSaveExecute／FmSelect.SaveWstcDialog | 拟合合格→保存曲线→已有曲线列表／名称→保存后退出。为保护已存方法，同名新增版本；曲线管理与方法绑定移到独立入口 |

核心证据：后端41项、前端20项；浏览器与冻结桌面各8组主流程／3种窗口主题组合，既有谱线10组／2布局回归通过。独立标量公式对照覆盖跨CCD二次拟合、误差符号和每步波长；无效波长、间隔界限、失效保存、同名版本、401／403和批量恢复有回归。真实方法页面选择新保存曲线并保存对应布局成功，原方法完整保持；冻结后端10点有效峰107重复3次保持一致。
