# 整套图标与旧版操作对应

本批覆盖已核对的38个带图标控件位置（主窗口27、右侧7、左侧4，含多样查看默认隐藏项），另重绘记录解锁与点位锁定，共40枚。全部资源都经本地Qwen重新生成，含首批12枚；不是把低分辨率原图直接放大。

| 旧版操作 | 本批对应与实际行为 |
|---|---|
| 上/下谱带、记录锁定/解锁 | 当前任务左侧已保存记录；边界禁用，选择仅改变观察源，不改右侧采集对象 |
| 上/下CCD、选择CCD | 以当前任务CCD安装索引切换；切换清空旧观察点与请求结果 |
| 十字线、滚动、区域放大 | 保留原观察处理函数，直接图标入口 |
| 适合图像、一线一点、一线四点 | 全幅、每点1屏幕像素、每点4屏幕像素；计入系统缩放 |
| 十倍CCD | 使用当前任务CCD点宽、屏幕宽度与分辨率，按物理10倍显示；不把它误做普通10倍放大 |
| 横向/纵向缩放、纵向还原 | 双轴独立控制；纵向还原保持横向范围 |
| 打印图像 | 样品/蒸发选中已保存谱带可生成当前可见范围PDF；原谱图查看打印入口与设置继续保留 |
| 增加/删除谱线、校正谱线、拟合曲线 | 正式色散任务中可展开现有谱线/拟合面板，使用原公开API完成定位、保存、二次拟合和发布/绑定；预热与运行时限制保持 |
| 校参考线 | 谱图查看参考校正工具复用同套图标；没有将观察偏移当作物理重新标定 |
| 输入送样号/输入样品编号 | 右侧打开下一样品准备；采后重命名保持。预录、插入、清除在既有样号页处理，保持队列位置与已采数据保护 |
| 开始/暂停测量 | 既有样品分析控制使用统一高清图标；不在摄谱时混入无上下文的分析写操作 |
| 试样/预热/停止/结束 | 试样与预热独立，一次点击完成当前一次；下一重复需人工点击。停止可安全收尾，结束返回任务列表，不丢已保存结果 |
| 多样查看 | 既有谱图查看保留叠加与优先曲线；旧侧栏该按钮默认隐藏，不为了图标数量强行增加重复入口 |
| 完成后显示 | 旧PerformOK会保存并RefreshBand到末项；新版正式样品完成/重复间等待时选中最新保存均值谱带，色散完成显示燃烧均值，采集中仍为实时帧 |

旧版按文件类型控制动作，并非38个按钮在所有模式都能执行。新版保留独立准备页、人工激发、权限、不可变结果和真实协议边界。跨文件叠加、全部历史样品、分析线程与实体打印的完整等价不在本批作出保证；本批没有修改历史源文件或用户库。

物理比例只读元数据：采集任务增加layout.point_width_um和profile.screen_width_mm/screen_resolution_px，色散任务增加后两项；没有schema迁移。图标来源逐枚见catalog.json。

验证中发现新增谱线误校验了旁边CCD间隔表单，已改为只校验谱线录入表单；没有舍弃旧间隔精度或放宽后台校验。桌面PDF验证在QA的WebView IPC处采集真实生成的PDF字节并模拟取消，未宣称操作实体打印或原生保存窗口。
