# 摄谱操作区按键位置对照

本批根据用户新旧局部截图，按键逐组对应，而非只做三栏分区。保留上批已经确认的新版导航、页头、明暗主题与显式返回入口。原始依据为`FmView.dfm`、`FmView.pas::BeforeShow`、`FmDockAwarePrepare.dfm`和`FmDockGuideIgnit.pas::SetBtns`；未修改旧源。

| 旧版位置 | 当前对应 |
| --- | --- |
| 色散工具栏最左端加／减 | 实际增加谱线、删除所选谱线移到谱线选择框之前 |
| 选择谱线 → 定位谱线 → 曝光区间 | 三字段连续排列；停止使用弹性填充把后续按钮推到最右端 |
| 曝光后定位、拟合、分隔、结束 | 色散定位／拟合紧跟曝光，结束位于同组末端；空闲色散不显示启动／暂停，正在运行或暂停时保留必要控制 |
| 非色散曝光后样号输入等操作 | 实际采后样号与任务详情图标回到曝光之后，随后为现有测量／暂停、结束；未补造无实现的参考线动作 |
| 第二排从左侧谱带面板之后开始 | 谱带前后、CCD前后／选择、十字、区域、平移、比例、双轴、打印顺序保留；侧栏比例调整为约17.5%／20%以接近本次参考 |
| 色散／蒸发左侧“谱带名称”一列 | 移除不适用的样品编号／序号列及顶部样品工具行；展示真实已保存谱帧／谱带，原记录锁定、最新和实时查看移入底部“记录操作” |
| 样品左侧记录表 | 记录号、样品编号、样品序号及原顶部工具保持 |
| 右侧灰色样号工具 | 色散的三个样号图标按旧位置保留并禁用，说明当前类型无需预录样号；没有新增样号写入动作 |

色散左表仍显示本任务真实谱帧，未更换为旧文件级存储模型；上方曝光与波长仍只读。色散定位、拟合、预热和采集业务、任务快照与权限均保持。

## 验证

浏览器17组／9布局、实际QA15组／9布局，采集回归浏览器与桌面各5组／8布局，前端15项和TypeScript/Vite通过。新增坐标核对：增加／删除位于选择框之前；定位在曝光右侧且间隔小于20 CSS像素；色散字段与按钮中心在同一水平线上；三种模式按钮顺序及表头列数正确。保留明暗、最小窗口、观察零写入、点值、CCD、缩放、PDF、人工重复、预录失败、只读权限与三线拟合回归。

记录操作通过展开后的实际按钮验证；空闲色散无暂停按钮是本批明确的类型规则，运行期间暂停／继续仍由原状态规则控制。正式／QA源码与资源一致，旧源和后端源码／EXE字节保持，写入隔离库。两个最终QA自然退出0、所属残留0。根目录配对程序已备份更新，关闭旧窗口后重开；安装包未更新，真实设备和实体打印仍另验。
