# 按钮弹出界面排版核对

七类原生 dialog 壳、两类 HTML 预览层及摄谱浮动处理层全部纳入。按实际按钮进入 31 个界面场景；每个场景验证 1440×1000、1060×680、2560×1200 × 明／暗主题，共 186 组，浏览器与冻结 Tauri 桌面分别通过。

验证弹层在视口内、无非表格横向滚动、输入控件不越界、末尾控件可滚动到达。实测窗口留在隔离色散任务详情；当前设备断开，模拟汞灯 stopped / safe_off=true。系统原生文件选择、确认／输入框采用操作系统排版；不把真实硬件验收计入本批。
