## 目标与实际变化

完成分析谱线的数据、API 和 React 编辑闭环。每个方法现在固有一条与方法参考条件同步的唯一参考基线，并可新增、编辑、删除、启停和排序分析线、内标线与定位线。

谱线参数覆盖理论/实际波长、关键波段与优先级、背景/定位/内标引用、无内标/背景内标/普通内标线三种模式、扫描宽度、背景偏移、最大值/高斯峰值、拟合函数、坐标、单位、含量/浓度、精度、有效范围、超限容差和标准点。实际曲线拟合和样品分析仍按计划留在后续步骤。

## 核心验收

- [x] 新建方法自动生成唯一参考基线；基线不能重复新增、改类型或删除，并随参考波长、实际波长、线宽和单位同步。
- [x] 支持四类谱线、按元素/波长排序、手动上下移、启停、关键波段和 0–100 优先级；它们全部进入方法版本内容与 SHA-256。
- [x] 输入波长后立即返回 CCD、点位、帧/转角位和角度，或返回全局越界、不在 CCD、CCD 未启用、安全边界越界等稳定原因码。
- [x] 执行 160–800 nm、实际偏移最大 0.3 nm、非基线 ±0.01 nm 近似重复、每方法最多 300 条和 CCD 安全范围规则。
- [x] 背景、定位、内标引用必须存在、类型正确且已启用；被引用谱线不能停用或删除；自引用、丢失引用与循环引用均有稳定错误码。
- [x] 高斯计算点只允许 3–9 奇数且不大于扫描宽度；最大值模式固定 1 点。
- [x] 单位、小数位、峰阈值、峰侧比、有效范围和超限容差完整校验；分析线必须有 4–50 个范围合法且不重复的标准点。
- [x] 所有谱线写操作都先校验完整候选集合，在单笔 SQLite 事务内创建新草稿并写审计；失败时版本计数不变。
- [x] 发布版本中的谱线、引用、标准点、关键标记和优先级不可变；后续编辑只产生新草稿，不改写当前有效版本。
- [x] 未登录谱线读取返回 401；`analyst` 可读不可写，写操作返回 403。
- [x] React 方法页提供条件/谱线分页、谱线列表、可检测提示、引用选择、峰值/拟合/范围表单和标准点表格；TypeScript 与 Vite 生产构建通过。

## 失败语义验证

- 近似重复波长、非法高斯点数和标准点不足均返回 `invalid_spectral_line` 及逐字段错误，版本号不变。
- 不存在引用返回 `line_reference_not_found`，停用被引用谱线返回 `line_reference_disabled`，删除被引用谱线返回 `spectral_line_in_use`。
- 循环引用校验返回 `line_reference_cycle`；全局越界和 CCD 不覆盖分别返回 `wavelength_out_of_global_range` 与 `wavelength_not_on_ccd`。
- 排序列表缺失、多余或重复返回 `line_reorder_mismatch`；不产生半成品草稿。
