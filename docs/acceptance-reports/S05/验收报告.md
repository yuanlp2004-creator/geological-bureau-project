## 目标与实际变化

完成方法条件、分析谱线和标准点的 HTML 预览、可检索文字 PDF 与打印闭环。纸张、方向、四边边距、标准/紧凑版式、字号、默认打印机、份数、单双面、彩色和打印前预览均作为本机默认设置持久化；预览、PDF 和打印任务复用同一份方法版本快照、字段行与分页模型。

后端可发现 Windows 系统打印机，并提供内置 `GeoSpectrum PDF（虚拟打印机）` 作为无交互自动验收通道。每个打印任务保存渲染输入和生成 PDF；虚拟打印成功后生成独立输出文件，系统调度失败则保留错误 PDF、输入快照和稳定错误码。分析报告和批量结果导出仍按计划留在后续步骤。

## 失败语义验证

- 未知打印机返回 `printer_not_found`；保存失败后旧默认值保持。
- 不存在的方法/版本沿用稳定的 `method_not_found` / `method_version_not_found`。
- 系统调度异常返回 `print_dispatch_failed`，响应包含任务 ID、输入路径、PDF 路径和底层原因；失败任务可通过任务 API 查询。
- 单次预览、PDF 或打印请求携带的临时页面设置不会自动写回默认值。
