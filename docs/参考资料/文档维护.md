# 文档维护

日常说明从 [文档首页](../README.md) 进入；软件现状以 [当前验收状态](../acceptance-reports/README.md)、现行使用说明和代码导读为准。

## 更新规则

- 当前页面只保留仍成立的功能、操作、约束与最新交付结论。
- 阶段结论、研究前快照、历次授权和旧手册结果统一进入 [历史记录](历史记录/README.md)，不在当前页面逐项展开。
- 原始验收报告、证据、计划执行哈希和旧资料保持可追溯；原文件路径继续保留，链接由历史索引集中管理。
- 正式文档留在现有职责目录，临时输出进入系统临时目录或 `app/.local/`。
